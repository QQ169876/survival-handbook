# 《穿越生存手册》

> 假如有一天你穿越回古代——这份手册就是你随身携带的"科技火种包"。
> 内容基于真实历史工艺与现代科学原理整理，多数技术为古代确实存在或现代可低成本复现的方案。

> ⚠ **先读 [`可信度说明.md`](可信度说明.md) 再用。**
> 本手册区分【史实】【科学】【经验】【存疑】四类内容：**没有标注为史实或科学的数字，一律视为经验值，必须现场验证。**
> 医疗相关（剂量、效价、疗程）本手册原则上不给数字——土法制品效价未知，给剂量等于害人。

## 为什么要做这个

许多穿越题材作品里，主角动辄"造蒸汽机、炼钢、发电"，却很少讲清楚**真实的技术门槛与实施顺序**。
本手册按"先活下来 → 再赚钱 → 后建产业"的逻辑编排，每一册都包含：材料在古代的获取方式、
可照做的步骤、失败排查表与安全红线。

## 使用顺序建议

0. 落地之前先读 `分册/21`（朝代选择与落地风险评估）—— 它把"选哪个朝代"换成"查清哪六件事"；
1. 先读 `分册/14`（净水与卫生）与 `分册/07`（盐糖）—— 生存刚需，且是最快变现的产业线；
2. 落地第一个冬天必须读 `分册/09`（制冰）—— 冰窖是一次错过要等一年的机会；
3. `分册/13`（止血驱虫驱兽）应在出门前读完——它是唯一不需要任何工业基础、立刻能用的手册；
4. 再读 `分册/02`（肥皂）—— 一周内可落地的生意与卫生基石；
5. `分册/01`（青霉素）—— 保命技术，永远优先；
6. `分册/17`（农业）与 `分册/20`（家常菜）决定能养多少人、能把日子过成什么样；
7. `分册/04`（冶炼）与 `分册/06`（发电）是长期工程，按册内阶段推进；
8. `分册/08`（味精鸡精）与 `分册/03`（香水）属高利润精细化工，等前三步站稳再做；
9. `分册/11`（纺织）与 `分册/12`（染色）组成第一条完整产业链，是进阶篇的优先项；
10. `分册/18`（通信）与 `分册/19`（捕兽陷阱）按需要随时读，先立规矩、后动手；
11. `分册/16`（医药进阶）先读它的劝退部分，再决定要不要动手；
12. `分册/15`（火药）最后再碰——本册的结论是能替代就不做；
13. `分册/10`（蒸汽机）与 `分册/05`（充电）排在最末：前者依赖前九册的全部基础且风险最高，
    后者先想清楚手机对你到底值多少工时。
