# 《穿越生存手册》

> 假如有一天你穿越回古代——这份手册就是你随身携带的"科技火种包"。
> 内容基于真实历史工艺与现代科学原理整理，多数技术为古代确实存在或现代可低成本复现的方案。

## 为什么要做这个

许多穿越题材作品里，主角动辄"造蒸汽机、炼钢、发电"，却很少讲清楚**真实的技术门槛与实施顺序**。
本手册按"先活下来 → 再赚钱 → 后建产业"的逻辑编排，每一册都包含：材料在古代的获取方式、
可照做的步骤、失败排查表与安全红线。

## 分册说明

| 分册 | 内容 | 一句话定位 |
|---|---|---|
| 01 青霉素 | 菌种识别→培养→过滤→酸化→炭吸→浓缩→皮试与用法 | 保命王牌：对付伤口感染与肺炎的土法抗生素 |
| 02 肥皂与香皂 | 草木灰制碱→皂化→盐析→熟成；香皂调香调色三条升级线 | 第一产业：成本最低、见效最快的生意与卫生基石 |
| 03 香水 | 水蒸气蒸馏、脂吸法、酒精酊剂；调香结构与配方 | 高利润奢侈品，兼产药露与高度酒 |
| 04 冶炼与窑炉 | 木炭窑→块炼铁→渗碳/炒钢/灌钢/坩埚钢→热处理；馒头窑烧砖、石灰窑 | 工业树主干：从石头到刀剑的完整路线 |
| 05 手机充电 | 手机供电要求（5V、接口识别）→ 人力/水力 → 整流 → 铅酸储能 → 稳压限流 | 明确告知：可行但性价比最低，优先级排最后 |
| 06 简易发电 | 伏打/丹尼尔/铅酸三电池；发电机结构；水力畜力电站；功率预算与安全 | 全系统电力中枢：化学起步，机械扩产 |
| 07 制盐与制糖 | 海盐晒盐/淋卤煎炼/井盐顿钻；粗盐提纯与海藻灰加碘；甘蔗榨汁→石灰澄清→连环锅熬煮→打砂→黄泥水淋脱色→冰糖；麦芽饴糖、甜菜补充 | 生存刚需与第一桶金：盐保命防腐，糖供能酿酒，两条最快变现的产业线 |
| 08 味精与鸡精 | 鲜味原理与相乘效应；昆布水提简易路线；面筋酸水解→等电点结晶→转钠→低温浓缩标准路线；酱油副产与酵母抽提物；鸡精配方与造粒、素鲜粉 | 鲜味工业：把面筋、豆渣、海带变成按两卖的高价调味品 |
| 09 制冰方法 | 冬季采冰与地下冰窖（凌阴）设计与损耗控制；硝石溶解制冷与硝石土法获取、回收闭环；陶罐冰箱与夜间辐射结冰；机械制冷为何不推荐 | 暂停时间的技术：保鲜、退热、存药与夏季暴利冷饮 |

## 纯文本资料说明

- **诗词三册**：唐诗精选 70 首、宋词精选 40 首、按场景检索的名句速查 200+ 句，全部公版，
  附"临场怎么用"与防翻车建议（穿越者抄诗指南）。
- **小说三册**：热门网文只收"清单+套路+桥段模板"（不复制版权正文）；
  古典名著与公版世界名著为完整内容库，附茶楼说书实操排期。

## 使用顺序建议

1. 先读 `分册/07`（盐糖）—— 生存刚需，且是最快变现的两条产业线；
2. 落地第一个冬天必须读 `分册/09`（制冰）—— 冰窖是一次错过要等一年的机会；
2. 再读 `分册/02`（肥皂）—— 一周内可落地的第二笔生意与卫生基石；
3. `分册/01`（青霉素）—— 保命技术，永远优先；
4. `分册/04`（冶炼）与 `分册/06`（发电）是长期工程，按册内阶段推进；
5. `分册/08`（味精鸡精）与 `分册/03`（香水）属高利润精细化工，等前三步站稳再做；
6. `分册/05`（充电）最后看，先想清楚手机对你到底值多少工时。
