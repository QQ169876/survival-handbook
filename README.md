# 《穿越生存手册》

> 假如有一天你穿越回古代——这份手册就是你随身携带的"科技火种包"。
> 内容基于真实历史工艺与现代科学原理整理，多数技术为古代确实存在或现代可低成本复现的方案。
>
> 有大智者阅后云："能背下来现在起码也得是个985"。

## 这套资料用在哪三种场合

它不只为"穿越"而写。凡是要**从零开始把技术重新搭一遍**的场合，顺序问题是同一个：

1. **穿越回古代**——本手册的主线场景；
2. **末世 / 灾难后的短期求生与长期重建**——同样要先解决水、火、感染、盐，
   再谈产业；很多条目不需要"古代"这个前提，现代废墟里照样适用；
3. **文明重启**——这是最硬的一种：所有技术按 [`科技树.md`](科技树.md) 的顺序
   逐层点亮，每一层的产出就是下一层的原料。

三种场合的区别只在**起点**：穿越是"有社会、没技术"，末世是"有残骸、没秩序"，
重启是"有知识、没任何东西"。阅读顺序应据此调整（见「使用顺序建议」）。

## 为什么要做这个

许多穿越题材作品里，主角动辄"造蒸汽机、炼钢、发电"，却很少讲清楚**真实的技术门槛与实施顺序**。
本手册按"先活下来 → 再赚钱 → 后建产业"的逻辑编排，每一册都包含：材料在古代的获取方式、
可照做的步骤、失败排查表与安全红线。

## 两个维度：编号 = 顺序，篇 = 门槛

分册有两条互相独立的排序轴，别混着看：

**① 编号 01~36：它在科技树上第几个被点亮。**
顺序见 [`科技树.md`](科技树.md)——生存 → 食物 → 手作坊 → 度量定向 → 火与金属
→ 基础化工 → 玻璃照明 → 机械动力 → 印刷 → 电与磁 → 精细化工 → 医药 → 典籍。
编号一旦分配就不再变动，引用时**只认编号不认目录**。

**② 篇：做它需要多少工业基础。** 判据只有一条：

> 做这件事，是否需要本手册里另一册提供的工业能力——
> **冶炼（16）、化工上游（17）、机械加工（21）、电力（24）、精密器皿与试剂**——作为前置？

- **不需要** → 基础篇（落地即可动手，材料现成，靠双手和火）
- **需要锅、陶器、草木灰、简单手工工具，但不需要冶炼与化工** → 作坊篇
- **需要冶炼／化工／机械／电力中至少一项** → **进阶篇**
- **不是技术，是典籍**（兵书原文与译文）→ 典籍篇

两轴分开的好处：某册技术路线变了、要在篇与篇之间挪动时，改目录即可，
编号与全部交叉引用都不受影响。以后新增的现代制造技术一类内容，一律进 **进阶篇**，
编号按 [`科技树.md`](科技树.md) 的层级定位插入。

## 使用顺序建议

**顺序不是拍脑袋排的，按五条轴判定，优先级从高到低：**

1. **时令窗口**——错过要等一年或一个季节的（采冰、留种播种、晒盐榨季），与时间赛跑，最优先；
2. **生存权重**——不解决就会死的（庇护所、水、止血、感染），其次；
3. **前置依赖**——被别的册默认「买得到」的上游（硫酸、酒精、碱、纸），排在被依赖者之前；
4. **现金流**——能最快养活后续工程的技术，排在吃钱的长期工程之前；
5. **风险与性价比**——风险越高、回报越低越靠后，先算账再动手。

按这五条，33 册分为十个阶段。**阶段之间不要颠倒；阶段内部先后不强求**，可按落地季节与手头资源并行推进。

### 阶段 0 · 落地前（决策）

- `分册/基础篇/01` 朝代选择与落地风险评估——它把「选哪个朝代」换成「查清哪六件事」：
  朝代不决定生死，落地点决定。册末的抵达后 72 小时清单直接对接阶段 1。
- `法律/05-律例速用与避坑`——法律不是知识，是风险敞口。落地先问清四件事：
  **这里归谁管、打官司去哪儿、通行的是什么例、我算什么人**；再记住十恶这条红线。

### 阶段 1 · 落地后 0~72 小时（先活过当下）

- `分册/基础篇/02` 野外求生技能——第一小时就按它办事：**庇护所 > 水 > 火 > 食物**，这个顺序不能反。
  人能撑的时间尺度是「三分钟没空气、三小时失温、三天没水、三周没食物」，优先级由此而来；
- `分册/基础篇/04` 野外止血·驱虫·驱兽——唯一不需要任何工业基础、随手可得、即刻可用的保命册；
- `分册/基础篇/03` 净水与卫生——取水点／住区／污物区三区分离**当天就要定死**，事后改代价最大；
  水比食物更能决定你能活多久；
- `分册/典籍篇/33` + `分册/典籍篇/32` 兵书白话卷与原文卷——第一天就要会说话：怎么开口、怎么自证无害、
  怎么让人听你的。它不教你做事，只教你怎么说话、怎么判断、怎么立住名分。
  先读 33 的白话，读通了再回头背 32 的原文——能引原文，才真的有分量。
- `分册/典籍篇/35` 经络穴位与针灸——没有药的时代随身携带的"药箱"。先背骨度分寸与急救十穴
  （人中、合谷、内关、足三里……），在自己身上练指压；针具可磨、艾绒可搓，
  这是唯一不需要供给线的医疗手段。孕妇与胸背红线当天记死。

### 阶段 2 · 第一个月（站稳脚跟 + 第一笔钱）

- `分册/作坊篇/08` 制盐与制糖——生存刚需兼最快变现的两条产业线；盐保命防腐，糖供能酿酒；
- `分册/作坊篇/10` 肥皂与香皂——一周内可落地，同时是卫生基石，成本最低、见效最快；
- `分册/基础篇/05` 家常菜与主食——把饭做像样，是把食物变成生意的前提。
- `经济/01` 货币与物价、`经济/02` 记账与成本核算——从第一笔进出账起就要立账，晚一天就补不回来；
  货币册的「三天校准法」（问米价 → 记成交价 → 定饭钱锚）应在落地第一周内做完，
  后续所有定价都以这个锚为准。

### 阶段 3 · 有时令窗口，错过要等一年（与时间赛跑）

落地季节决定这三条谁先谁后。**能做的立刻做，不能做的当场记进日历**：

- `分册/作坊篇/11` 制冰——采冰只在冬天，冰窖是一次错过要等一年的机会；硝石制冷与机械制冷可后补；
- `分册/基础篇/07` 农业增产——留种、试种、粪肥腐熟必须赶在播种季之前，当年错过就整年靠买粮；
- `经济/04` 税赋与徭役——征收有固定月份（夏税秋粮），落地第一周就要问清，
  备银须提前两个月；它同样属于「错过要等一年」的窗口，且错过的是罚不是钱。
- `分册/典籍篇/34` 本草图鉴——药材采集全是时令：金银花夏初含苞、连翘秋初果熟、
  根类秋后采，花期错过药性即散。借阶段 3 把"认药"与"按季采药"的日历一起立起来。

### 阶段 4 · 第一个半年（保命技术 + 上游化工）

- `分册/进阶篇/30` 青霉素——感染是穿越者头号死因，本该更早；但它需要洁净环境与稳定温度，
  必须等阶段 1 的卫生与阶段 2 的场地站稳，活性炭与酸化还要借 `分册/进阶篇/17`；
- `分册/进阶篇/17` 基础化学品（上游母册）——**先硫酸，后一切**。任何一册出现「默认买得到硫酸／
  盐酸／硝酸／明矾」时，就该回到这一册；建议与 30 并行起步；
- `分册/作坊篇/09` 酿酒与蒸馏——消毒、溶剂、燃料、现金四条命脉一身挑，果酒蜜酒不必等粮食宽裕，
  落地第一年就能做；守死掐头去尾的甲醇红线，留意禁酒榷酒风险。
- `分册/典籍篇/36` 经典方剂——辨证框架（八纲）与常用方二十首在本阶段读，与册 30/31 并行：
  感染走青霉素，其余大部分问题走本草线。方剂剂量只录原书、不做现代换算。

### 阶段 5 · 第一至第二年（工业树主干）

- `分册/进阶篇/16` 冶炼与窑炉——从木炭窑到块炼铁、炒钢灌钢，是所有工具与机械的根；
- `分册/进阶篇/24` 简易发电——化学电池起步、机械扩产；先算功率预算，再决定造不造机器。

### 阶段 6 · 产业链（可并行，按你所在地方缺什么选）

- 布匹链：`分册/进阶篇/21` 纺织机械 → `分册/作坊篇/13` 染色 → `分册/作坊篇/14` 印花防染（到此才闭环）；
  这条链门槛最低、回报最线性、需求无上限；
- 知识链：`分册/作坊篇/12` 造纸 → `分册/进阶篇/23` 印刷（**先雕版，别先做活字**）；纸让契约、账目、
  医方、书籍得以流转，是穿越者真正的杠杆；
- 精细化工：`分册/进阶篇/27` 香水、`分册/进阶篇/28` 味精鸡精——依赖阶段 4 的酒精与酸碱，站稳再做；
- 管理线（与人、钱同步增长，不属技术但决定成败）：`经济/03` 契约合伙与票据、
  `经济/05` 用人与管理、`经济/06` 定价与经营——一旦超过五个人、三笔往来，
  问题就从"做不做得出来"变成"管不管得住"，这三册应在本阶段一次读完。

### 阶段 7 · 按需取用（无固定次序）

- `分册/基础篇/15` 指南针与定向导航——在远行、勘测、布设驿路之前读（磁偏角必须校正，只解决方向不解决位置）；
- `分册/进阶篇/26` 通信——第一件事是约定码表，第二件事是回执；先立规矩，后建烽火；
- `分册/基础篇/06` 简易捕兽器与陷阱——只在需要补充蛋白与皮毛时做，选址大于机关，安全大于收获。
- `经济/07` 官商关系与风险——开工前先跑一趟衙门，问清"要引不要、要课不要"；
  这一趟能省下全部家当。被勒索、遇摊派、要止损时，也回到这一册。

### 阶段 8 · 高级材料（前面全都站住了才养得起）

- `分册/进阶篇/19` 玻璃——吃燃料（1400~1500℃ 坩埚窑），依赖阶段 5 的窑炉与稳定燃料供给；
- `分册/进阶篇/20` 照明与灯具——**玻璃之后的第一条产线**：燃烧四要素、灯芯那一刀、
  烟囱效应让罩灯更亮更省油、反光聚光布灯三招。油灯部分落地第一夜就能用，
  罩与提亮要等册 19；照明不点亮，夜间接生、缝合、记账这些细活都做不了。
- `分册/进阶篇/29` 塑料与人造高分子——吃三酸与混酸，依赖阶段 4 的化工上游；动手前先问一句
  木匠陶匠能不能替代。

### 阶段 9 · 高风险 / 低性价比，先算账再动手

- `分册/进阶篇/31` 医药进阶——先读它的劝退部分，再决定要不要动手；剂量一律不给；
- `分册/进阶篇/18` 火药与安全——本册的结论是能替代就不做；
- `分册/进阶篇/22` 蒸汽机——依赖前面几乎所有册且风险最高，先算功率与燃料账；
- `分册/进阶篇/25` 手机充电——可行但性价比最低，先想清楚手机对你到底值多少工时；
- `电力/01` 给手机充电——与 `分册/进阶篇/25`、`分册/进阶篇/24` 配套的实操手册：接口识别（D+／D- 短接、
  Type-C 上拉三档、苹果分压、Lightning 不要自制）、科技树六级 L0~L5、极限方案评估、
  没有万用表时怎么测、人的功率预算。**排在这阶段只是因为"值不值"由册 25 决定；
  若册 24 已经跑通，本册可以提前到那时就读。**

## 新增资料时怎么排（判定流程）

新增或大修一份资料后，按下面的顺序问一遍，落到哪个阶段就是哪个阶段：

1. 有没有时令窗口（错过要等一年或一季）？→ **阶段 3**；
2. 落地 72 小时内不解决会不会死？→ **阶段 1**；
3. 是不是别的册默认「买得到」的上游原料？→ 排在被依赖的册之前，通常落到 **阶段 4**；
4. 有没有明确前置链？→ 紧排在前置册之后（布匹链 21→13→14、知识链 12→23、玻璃照明 19→20）；
5. 风险高到「能替代就不做」，或性价比明显偏低？→ **阶段 9**；
6. 其余按生存权重与现金流排进 **阶段 2 / 5 / 6 / 7 / 8**。

排完还要做三件事：

1. 到 [`科技树.md`](科技树.md) 里找到它属于哪一层，把状态从 ⬜ 改成 ✅ 并写上资料位置；
2. 到 [`资料来源.md`](资料来源.md) 里登记来源（甲类给底本链接，乙类给核对方向，不许伪造引用）；
3. 同步更新上面的「排序依据速查表」，然后跑一次 `python _build/check_order.py`——
   它会核对 `分册/` 目录与速查表，把漏排的册子列出来。
