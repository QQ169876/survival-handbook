### 1. 这一层解决什么问题：先让它继续转，再谈造

【经验】内燃机在末世语境里的价值，是把"人力/畜力"换成"一小时顶几十个人"的动力，
并且它是**可移动的**（这点水车与蒸汽机都不行）。

但本册的立场必须先讲清楚，免得读偏：

- **修，是可行且高回报的**：一台缺保养、缺一个垫片、油路堵了的机器，
  修好它只需工具与判断；
- **造整机，明确劝退**：不是原理不懂，是门槛在别处（见第 4 节）。

【判据】**"附近有坏的"永远优于"自己做新的"**（工艺 13 的同一条算术）。

【史实】可核对的时间线（公开机械史常识）：
- 1876 年奥托制成实用的四冲程煤气机；
- 1885~1886 年奔驰、戴姆勒分别做出以汽油机为动力的早期汽车；
- 1897 年狄塞尔做出压燃式柴油机；
- 1913 年福特移动装配线，前提是零件已可互换（见 工艺 14）；
- 20 世纪后期化油器逐步被电子燃油喷射取代。

### 3. 原理：四个冲程与"四要素"

#### 3.1 四个冲程（四冲程循环）

【科学】不管是汽油机还是柴油机，四冲程都是同一个骨架：

1. **进气**：活塞下行，进气门开，吸入空气（汽油机吸入的是空气与燃油的混合气）；
2. **压缩**：两门关闭，活塞上行压缩，**气体温度大幅升高**（这是着火的前提）；
3. **做功（膨胀）**：燃烧使压力骤升，推动活塞下行——**这是唯一对外输出功的冲程**；
4. **排气**：排气门开，活塞上行推出废气。

【科学】汽油机与柴油机的根本区别在**着火方式**：

- **汽油机（点燃）**：压缩的是混合气，靠电火花点火。
  【判据】压缩不能太高，否则混合气会在火花之前自燃，产生**爆震（敲缸）**；
- **柴油机（压燃）**：压缩的是纯空气，压缩比高，空气温度足以
  让喷入的燃油**自行着火**，**没有火花塞**。
  【判据】因此柴油机更依赖**压缩压力**与**喷油雾化**。

#### 3.2 "四要素"：所有故障都能归到这四条

【经验】判断一台机器为什么不工作，只看四件事：

| 要素 | 汽油机 | 柴油机 |
|---|---|---|
| ① 压缩够不够 | 压缩压力不足 → 不着或无力 | 压缩不足 → **根本不着**（压燃靠它） |
| ② 燃料对不对、到不到位 | 混合气过浓/过稀 | 喷油量、雾化与喷油正时 |
| ③ 点火/着火时机对不对 | 火花存在且正时正确 | 喷油正时正确 |
| ④ 进排气通不通 | 空滤堵、排气堵 | 空滤堵、排气堵、增压器失效 |

【判据】**"不着车"的排查顺序永远是：压缩 → 燃料 → 点火（或喷油）→ 进排气。**
不要跳过第一步去调化油器——**没有压缩，后面三样调得再好也没用。**

#### 3.3 两大机构与几个系统

【经验】理解一台发动机，把它拆成"骨头"和"内脏"：

- **曲柄连杆机构**（活塞、连杆、曲轴、飞轮）：把往复变成旋转；
- **配气机构**（凸轮、气门、正时）：**让该开的门在正确时刻开**；
  【红线】正时错乱会让活塞撞气门，**这是修发动机最贵的一种错误**；
- **润滑系统**：油膜隔开所有相对运动面（工艺 11）；
- **冷却系统**：**不是"让它凉"，而是"让它处在合适的温度区间"**；
- **燃料系统**：化油器/喷油泵/喷油器——把油变成能与空气混合的雾；
- **点火与启动**（汽油机）：火花塞、高压、蓄电池或手摇启动。

### 4. 为什么造不出来：内燃机的真实门槛

【经验】很多人以为内燃机难在"原理复杂"，其实原理半天就讲完了。
难的是**同时满足四件事**：

1. **高精度配合**：活塞与缸壁的间隙要小到不漏气、又大到不卡死；
   曲轴轴颈与轴瓦要有能形成油膜的间隙——**这是工艺 08 与工艺 14 的极限**；
2. **材料与热处理**：曲轴受交变载荷（疲劳）、气门受高温与冲击、
   活塞受热膨胀——都需要合格材料与热处理（册 16、工艺 03）；
3. **燃料品质**：爆震、积碳、胶质、含水——**没有合格燃料，机器几天就废**；
4. **配套链**：起动电机、发电机、蓄电池、滤清器、散热器、密封件，
   **缺一样都转不起来**。

【判据】四问定取舍：
1. 有没有能加工缸孔与曲轴的设备与量具？（没有 → 不做整机）
2. 有没有合格的燃料，且能持续供应？（没有 → **先解决燃料，别碰机器**）
3. 有没有橡胶密封件与滤材的来源？（没有 → 修都困难）
4. 有没有能铸造缸体、缸盖的能力？（没有 → 停在"单缸改制"层面）

【经验】**可行的替代路径**：
固定式动力优先考虑蒸汽（册 22）与水力（农业 02）；
移动式动力，优先**修复现有的内燃机**，其次考虑**外燃机/燃气发生器**路线。

### 5. 燃料：性质差别、代用与红线

【科学】两类燃料的关键差别（只作定性理解）：

- **汽油类**：易点燃、需火花，**抗爆性**（抵抗自燃的能力）不足会敲缸，
  长期敲缸会打烂活塞与轴瓦；
- **柴油类**：靠压燃，看重**自燃性**；黏度大、雾化要求高，
  **含水与杂质会迅速损坏精密的喷油偶件**。

【经验】代用燃料的三条历史路线（**只写原理，不给参数与配方**）：

1. **煤气/木炭气**：【科学】用燃气发生器把木炭或煤在缺氧条件下气化
   （原理见 化工 01），得到的可燃气经**除尘、冷却**后进入发动机；
   【史实】这种"煤气发生器汽车"在 20 世纪燃料短缺时期被大量使用过；
   【红线】产物含**一氧化碳**，无色无味，**室内、车库、帐篷内运行等于自杀**；
2. **酒精类**：【科学】酒精可替代部分汽油作为点燃式发动机的燃料，
   但它与汽油在热值、挥发性、吸水性上差别明显，
   需调整混合比并注意**吸水与腐蚀**；
   【红线】需要精馏与浓度控制（见册 09 的甲醇风险），**不得用未经处理的发酵液**；
3. **植物油与生物柴油**：【科学】植物油黏度大，直接长期使用会积碳与结胶；
   通过酯交换降低黏度是通行做法，**本册只写原理，
   不给任何配方、配比、催化剂与工艺参数**（见 工艺 06 油脂化学）。

【判据】燃料使用的四条硬规则：

1. **先过滤、后沉淀、再使用**：干净的燃料比什么都重要；
2. **不明来源的油，先小量试用并观察**；
3. **存放要避火、避晒、防潮、密封**，容器要有标识；
4. **改燃料必先改机器，且要在小负荷下试**——
   【红线】**不得在未确认安全的情况下载人载货试车**。

### 6. 五级台阶：从保养到自制

#### 台阶一：保养——让现成的机器继续转（收益最高）

【经验】保养清单（按重要性排序）：

1. **机油**：液位、油质、定期更换（见工艺 11 的换油判据）；
2. **空气滤清器**：**进灰等于往缸里撒砂纸**，这是缩短寿命的头号原因；
3. **燃料滤清器与沉淀杯**：放水、放杂质；
4. **冷却液与散热器**：液位、水垢、漏水、风扇与皮带张紧；
5. **紧固与检查**：地脚、进排气接头、管路卡箍（振动会松一切）；
6. **蓄电池与电气接头**：清洁、紧固、防腐。

【判据】保养做对了的标志：**启动容易、排气无色、水温稳定、机油消耗正常。**

#### 台阶二：故障诊断——按"四要素"逐一排除

见第 8 节排查表。核心纪律：**一次只动一个变量，动完要复原。**

#### 台阶三：部件修复——能修的与不能修的

- **可修（中低难度）**：油路与气道清洗、密封件更换、管路、
  散热器补漏、化油器清洗、电气回路、皮带与张紧、水泵、滤清器；
- **可修（需要母机与量具）**：气门研磨与密封检查、缸盖平面度、
  活塞环更换与间隙检查、轴瓦检查与更换、曲轴轴颈修复（见工艺 13 台阶三）；
- **不可修，只能换或报废**：有裂纹的缸体/缸盖/曲轴、
  拉伤严重的缸壁（超过可恢复范围）、断了的曲轴、变形的连杆。

【判据】**"能不能修"的判据是：失效在表面还是在基体。**
（与 工艺 13 第 3 节的同一条物理判断。）

#### 台阶四：代用与改制——最容易翻车的一级

- **代用件**：按 工艺 14 的三原则（参数不低于、装得下、定义一致）；
  【红线】**制动、转向、承载、吊装相关件一律不代用**；
- **代用燃料**：见第 5 节，必须**先空负荷试验、再逐步加载**；
- **改制**：改动结构、加大负荷、改用途的，
  【判据】改完必须**重新核算强度、重新试车、留记录**，
  且第一次试车**远程或隔离操作**。

#### 台阶五：整机自制——明确劝退

【判据】回到第 4 节四问。**四问中有任何一问答不上来，就不要开始。**
【经验】更现实的目标是"**单缸、低速、固定式**"的简易内燃装置，
即便如此，也需要完整的母机、材料与检测链条。
**在末世前十年，把资源投给"修"的回报，远高于投给"造"。**

### 7. 汽车底盘：制动优先

【经验】一辆车分四大系统，**优先级与学习顺序**如下：

1. **制动（最优先）**：能跑不算本事，**能停才算**；
2. **转向**：失控的第二个来源；
3. **行驶系**（车架、悬架、轮胎、轮毂轴承）：承载与稳定；
4. **传动系**（离合、变速、传动轴、差速器）：把动力送到轮子。

【判据】**每次出车前的三项检查**（照做即可）：
1. **制动**：踏板行程与脚感、是否跑偏、有无渗漏；
2. **轮胎**：气压、外伤、花纹、螺栓紧固；
3. **转向与灯光**：自由行程是否过大、喇叭与灯是否亮。

【经验】轮胎是末世里最先耗尽的资源之一：
【判据】**修补与翻新优先于替换**（见工艺 13 再制造、分册 29 橡胶），
且**同一轴上的轮胎规格与磨损程度必须一致**，否则制动会跑偏。

【红线】
- **制动系统任何维修后，必须在安全场地低速试刹确认**，再上路；
- **不许在坡度上仅靠千斤顶支撑作业**，必须用垫块/支架（工艺 13 同条）；
- **不许拆除或短接制动、限速、联锁装置**；
- **载运人员时，速度与安全距离按最坏路况取**，不按空载取。

### 8. 判据与故障排查

| 现象 | 优先怀疑 | 先查什么 |
|---|---|---|
| 完全启动不了 | 无燃料、无火、无压缩、启动系统 | 燃料到位 → 火花/喷油 → 压缩 → 电瓶与线路 |
| 启动后即熄火 | 燃料供给不畅、进气受阻、怠速调整 | 滤芯 → 管路气阻 → 排气是否堵塞 |
| 无力、爬坡差 | 压缩不足、进气堵、燃料不足、制动拖滞 | 空滤 → 压缩 → 油路 → 是否刹车没回 |
| 冒黑烟 | 燃烧不完全（混合气过浓/进气不足） | 空滤 → 负载是否过重 → 燃料供给 |
| 冒蓝烟 | 烧机油（活塞环/气门导管磨损） | 查机油消耗量 → 查缸压与窜气 |
| 冒白烟（持续） | 冷却液进入燃烧室或燃料含水 | 查冷却液液位是否下降 → 查机油是否乳化 |
| 过热 | 冷却液不足、水垢、水泵/风扇/皮带、负荷过大 | **停机降温后再开盖** → 液位 → 皮带 → 散热器 |
| 异响（敲击） | 爆震、轴瓦间隙过大、正时/配气异常 | 查燃料 → 查机油压力 → 查配气 |
| 机油乳化（发白） | 进水 | 立即停用 → 查缸垫与水路 → 换油 |
| 机油压力低 | 油量不足、泵与滤网、轴瓦间隙过大 | 立即停机 → 查油位 → 查滤网 |
| 油耗明显升高 | 泄漏、胎压、制动拖滞、燃烧恶化 | 查外漏 → 胎压 → 制动回位 → 空滤 |
| 制动变软/跑偏 | 有空气、渗漏、摩擦件磨损、两侧不一致 | **立即停用** → 查渗漏 → 排气 → 查摩擦件 |

【经验】**"仪表/指示灯亮"要当成命令，不是提示。**
机油压力与水温两项异常，**立刻停机**，不要"开到前面再说"。

### 9. 安全红线（本册最重要的一节）

1. **一氧化碳（CO）**：无色无味，废气中含量高。
   【红线】**严禁在室内、车库、地窖、帐篷内运行发动机**；
   排气必须引出室外并位于**下风向远离人畜与进风口**。
   【医疗红线】怀疑中毒：**立即脱离现场、转移到空气新鲜处、保持呼吸道通畅、
   尽快送医，本册不给任何药物与剂量**（见 化工 01、医学 01）。
2. **火灾**：燃料、机油、高温排气、电气短路四者同在。
   【红线】**随车/随机器配备灭火手段**；加油必须**停机、禁火、防静电**；
   严禁用汽油清洗零件与洗手（经皮吸收与火灾双重风险——用专用清洗剂或碱性水基清洗）。
3. **高温与压力**：散热器/冷却系统在高温时带压。
   【红线】**必须彻底冷却后，用布包住盖、缓慢开启并侧身避开**——
   瞬间喷出的高温液体会造成严重烫伤。
4. **旋转件与卷入**：风扇、皮带、飞轮、传动轴。
   【红线】**运转中不靠近、不摘护罩、不穿宽松衣物、不戴可缠绕的手套与饰品**；
   长发必须束起。
5. **蓄电池**：充电时产生**氢气**（可爆），电解液为强酸。
   【红线】**远离火源、通风、护目**；跨接启动**先正后负、拆时相反**，
   并避免工具同时碰正负极造成短路。
6. **支撑与顶升**：【红线】**千斤顶只是顶升工具，不是支撑工具**，
   车下作业必须加垫块/支架，且拉紧手刹、塞住车轮。
7. **试车**：【红线】试车必须在**空旷、无人、无障碍**的场地，
   先低速、先无载；**制动未确认前不得上路**；启动时注意是否会突然移动
   （挂档启动会"窜车"——**启动前确认空档**）。
8. **废油与废液**：【红线】机油、冷却液、废电池**集中收集、不倒入土壤与水源**
   （见 化工 01、L31 固废）。
9. **不许载人试改装车**：任何燃料、制动、转向、结构改动后，
   **未经过隔离试车与复检，一律不得载人**。
