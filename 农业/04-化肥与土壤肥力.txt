### 1. 这一层解决什么问题：地力是唯一的复利

【经验】种地的账和工业不一样：**机器会折旧，地力可以复利。**
同一块地，会养的越种越肥，不会养的三年就废。

【判据】亩产这件事上，**最短的那块板往往不是种子，也不是水，是肥力。**
分册 07《农业增产》讲的是"怎么种"，本册讲的是"凭什么长"——
两册是一件事的两半。

【经验】本册的态度必须先说清楚，免得读偏：

- **先做不花钱的三件事**：有机质、轮作（含豆科）、草木灰与粪肥的腐熟还田。
  这三件事在古代条件下完全做得到，且收益最大；
- **再做能就地取得的矿物肥**：骨粉、石灰、泥炭、鸟粪、硝石土；
- **合成氨与现代化肥：明确劝退**——不是它没用，是它的门槛不在化学，在工业。

【史实】化肥的历史节点（公开常识，可自行核对）：
- 1840 年李比希提出**矿质营养学说**与**最小养分律**，
  推翻了当时流行的"腐殖质营养说"；
- 1840 年代英国人劳斯建厂生产**过磷酸钙**（用硫酸处理磷矿/骨粉），
  这是第一种工业化肥；
- 19 世纪智利硝石（硝酸钠）大量出口，是最早的氮肥来源之一；
- 1909 年哈伯在实验室实现合成氨，1910 年代博世完成工业化（哈伯—博世法）；
- 20 世纪中叶的"绿色革命"建立在化肥、灌溉与良种三条腿上。

【经验】把这段历史读成一句话：**人类在 1913 年之前，靠的全是本册第 5 节
台阶一与台阶二那几招。** 所以不要因为造不出合成氨就觉得种不了地。

### 3. 原理：植物吃什么，土壤凭什么给

#### 3.1 植物吃什么

【科学】植物必需元素有十几种，其中：

- **大量元素**：碳氢氧（来自空气和水，不靠施肥）、
  **氮（N）、磷（P）、钾（K）**——农业上常说的"肥料三要素"；
- **中量元素**：钙、镁、硫；
- **微量元素**：铁、锰、锌、铜、硼、钼、氯等，**需求极少但不可缺**。

【经验】三要素的作用，只记一件最要紧的：

- **氮**：长叶子与茎，是"绿"的（蛋白质与叶绿素的核心成分）。
  缺氮 → 老叶先发黄、植株矮小；
- **磷**：长根与种子，是"结实"的（能量代谢与核酸）。
  缺磷 → 根系差、分蘖少、成熟晚、叶色暗绿甚至发紫；
- **钾**：管运输与抗逆（水分调节、酶活化、茎秆强度）。
  缺钾 → 老叶叶尖叶缘焦枯、茎秆软、易倒伏易病。

【判据】**看症状先分"新叶还是老叶"**：
氮、磷、钾在植物体内能转移，**缺了就从老叶调走**，所以缺素多先从老叶表现；
铁、钙等不易转移的，**症状先在新叶**。
【存疑】缺素症状常与病害、药害、旱涝混淆，**单凭叶色判断只能当线索，不能当结论**——
要用"试施对照"（一小块试，看是否改善）来确认。

#### 3.2 最小养分律（李比希的"木桶"）

【科学】产量不由含量最丰富的那种养分决定，而由**相对最缺的那一种**决定。

【经验】这条定律的实践价值极大，也极容易被误用：

- **对的一面**：盲目多施某一种肥，产量不会上去，只会浪费并可能受害；
- **容易错的一面**：最小养分是**会变的**——补了氮之后，短板可能变成磷或水。

【判据】**每次只补一种，一小块作对照，看反应再推广。**
这是没有化验室时唯一可靠的办法（与 工艺 13 的"一次只换一个"同理）。

#### 3.3 土壤凭什么给：肥力的四个支柱

【经验】土壤不只是"装肥的袋子"，它同时提供四样东西：

1. **水**（保水与排水）；
2. **肥**（养分储量与供应能力）；
3. **气**（根系要呼吸，板结与水淹都会缺氧）；
4. **热**（地温影响发芽与微生物活动）。

【科学】其中起枢纽作用的是**有机质与团粒结构**：

- 有机质分解时缓慢释放养分，是天然的缓释肥；
- 有机质与黏粒形成团粒，让土壤**既保水又透气**；
- 有机质是微生物的食物，而微生物才是真正的"养分转换车间"。

【判据】**保住有机质 = 同时解决水、肥、气三件事。**
这条比任何单一肥都重要。

【科学】**酸碱度（pH）**决定养分能不能被吸收：
强酸或强碱条件下，很多养分被固定住，"土里有，植物吃不到"。
【经验】长期大量施用某些氮肥会使土壤酸化，
酸性土用石灰（钙）改良——**这是古代就有的做法，且有效。**
【判据】改酸要**少量多次**，一次猛施石灰会烧坏土壤生物并造成微量元素缺失。

### 4. 判据：不化验，怎么知道地缺什么

【经验】没有化验室时，用"五个看得见的信号"：

1. **看土色与土层**：表层发白、板结、裂纹大 → 有机质低；
   土层下面有硬磐（犁底层）→ 根系下不去，水也下不去；
2. **看土性与结构**：抓一把湿土能捏成团、轻碰即散 → 结构好；
   捏成硬块摔不散 → 黏重板结；一松手就散、握不成团 → 砂性过重，保水保肥差；
3. **看杂草群落**（最省钱的生物指示）：
   特定的杂草偏好特定的土壤条件，地里自然长什么，本身就是一份报告。
   【判据】**先记下你这块地上的优势杂草，年年对比**——
   它的变化比任何一次目测都可靠；
4. **简易酸碱判断**：用植物指示剂（如紫甘蓝、黑豆皮等天然色素浸出液）
   对土壤浸出液做粗略变色判断；
   【经验】土法用"醋/草木灰水是否起泡"只能粗略判断**是否含游离碳酸盐**，
   **不能给出 pH 值**，【存疑】级别的结论，只作参考；
5. **看作物本身**：长势、叶色、是否早衰、是否只长秧不结实（见第 8 节表）。

【判据】**最高级也最可靠的一招永远是"小区试验"**：
在同一块地里划三小块——不施、施 A、施 B，其他管理完全相同，
收获时分别称重。**这条土办法胜过任何目测。**

### 5. 四级台阶：从"不花钱的"到"做不出来的"

#### 台阶一：有机质、轮作与豆科（先做这个，做一辈子）

- **堆肥与厩肥腐熟**：粪肥**必须腐熟后使用**（未腐熟会在土里二次发酵烧根，
  并带入病原与草籽）。【判据】腐熟的标准：颜色黑褐、无臭味、
  温度降到接近环境温、材料已看不出原形；
- **秸秆还田与覆盖**：还田要配氮（微生物分解秸秆本身要消耗氮），
  否则会出现"苗发黄"的暂时缺氮；
- **豆科轮作/间作**：【科学】豆科与根瘤菌共生固氮，
  这是古代农业能持续千年的核心机制；
- **绿肥**：翻压豆科或十字花科鲜草入土，是最快的有机质补充。

【判据】台阶一做到位的标志：**土变松、色变深、蚯蚓变多。**
蚯蚓数量是最直观也最诚实的地力指标。

#### 台阶二：草木灰、骨粉与农家肥（就地取材）

- **草木灰**：主要含钾与钙，碱性，兼可改酸与驱虫（见分册 07、工艺 12）。
  【判据】**灰要干燥存放，遇水即流失钾**；灰不能与粪尿混堆（碱性使氮挥发成氨）；
- **骨粉**：含磷与钙。【经验】骨需**充分煅烧后粉碎**才好被吸收，
  生骨粉见效极慢；
- **人畜粪尿**：肥效快但**卫生风险最高**（见第 7 节红线）；
- **泥炭、塘泥、河泥、旧墙土、灶土**：有机质与矿质的传统来源，就地可得。

#### 台阶三：矿物肥与"用酸处理"（需要化工前置）

- **磷矿/骨粉 + 硫酸 → 过磷酸钙**：【科学】原理是把不溶的磷酸盐
  转化为可溶的磷酸二氢盐。**只写原理。**
  【红线】硫酸属于高危化学品，**不给配比、不给操作步骤**
  （见册 17、化工 01 的危化品红线）；
- **硝石（硝酸钠/硝酸钾）**：天然硝石土可通过**淋溶—结晶**提取，
  【史实】这是历史上长期使用的方法；
  【红线】硝石同时是火药原料，**受管制**（见册 18、法律 01~04、经济 07），
  大量囤积与私下买卖都可能引祸；
- **石灰**：煅烧石灰石得到，用于改酸与补钙（见化工 03、册 16）。

【判据】台阶三的进入条件：**你的硫酸产能已经稳定，且有多余。**
【经验】在硫酸之前谈"自制磷肥"，是本末倒置。

#### 台阶四：合成氨（哈伯—博世法）——明确劝退

【科学】原理一句话：氮气与氢气在**高温、高压、催化剂**条件下直接合成氨。
难的不是这个反应式，是它身后的整套工业：

- 高纯氮（空气分离）与高纯氢（来自水煤气/天然气重整）的大量稳定供应；
- 能长期承受高温高压的**合金钢反应器**与**高压压缩机**（册 16、工艺 08、工艺 11）；
- 催化剂的制备（本册不给任何配方）；
- **巨大的能量投入**——合成氨本质上是在"把电和燃料变成氮肥"。

【判据】**四问定生死**：
1. 有没有稳定的大型高压设备与检测手段？（没有 → 停下）
2. 有没有廉价的大规模能源？（没有 → 停下，能源账算不过来）
3. 有没有能把氨进一步做成安全肥料的化工链？（没有 → 得到氨也没法安全施用）
4. 人员有没有高压、有毒、易爆作业的经验？（没有 → **这是拿命试**）

【红线】**本册不给合成氨的任何压力、温度、催化剂与流程参数。**
氨有毒、可燃、与空气混合可爆，液氨会造成严重冻伤；
硝酸铵既是肥也是炸药原料，**历史上多次重大爆炸事故与其有关**——
它属于"只认知、不储存、不自制"的一类。

### 6. 施肥的判据：什么时候施、施在哪、施多少算多

【经验】六条通用判据（不给数量，只给原则）：

1. **分次少量，胜过一次猛施**：一次施太多，植物用不完，
   剩下的不是流失就是"烧苗"；
2. **施在根区，不要撒在表面**：【科学】根系吸收靠水做介质，
   肥料要溶解后才能被吸收；表施的氮很容易挥发损失；
3. **趁墒施，或施后灌水**：干土施肥等于白施；
4. **氮分次追、磷钾作基肥**：氮易流失且需求集中在旺长期，
   磷钾移动慢宜早施深施；
5. **与有机质一起施**：有机质缓冲肥力、减少流失；
6. **先试一小块**：任何新肥、新来源，**先小面积试、看一季再推广**。

【科学】**"烧苗"的机理**：施肥使根际土壤溶液浓度过高，
渗透压反向把根里的水"吸"出来，表现为萎蔫枯死——**它是脱水，不是中毒。**
【判据】因此**浓肥必须离根、必须稀释、必须配合灌水**。

【判据】**施多了的三个信号**：
（1）叶色浓绿但徒长、易倒伏易病；（2）土壤表面发白结晶（盐渍化）；
（3）附近水沟长满藻类、水体发臭（富营养化）。
【经验】出现任何一个，立即停施并灌水洗盐／改种绿肥吸收。

### 7. 安全红线（本册最重要的一节）

1. **人畜粪尿必须腐熟**：【科学】未腐熟粪肥携带寄生虫卵、致病菌，
   是多种肠道传染病与人畜共患病的传播途径。
   【红线】**禁止直接浇施生粪**；禁止用生粪浇施**生食的叶菜与根茎类**；
   施用后**不得立即采收**；作业人员要洗手、要有专用工具（见分册 03、
   农业 03 的人畜共患病红线）。
2. **氮肥与饮水**：【科学】过量氮随水渗入可污染井水。
   【红线】**施肥区与取水点必须保持距离并位于取水点下游**
   （分册 03 的三区分离同样适用于此）。
3. **氨与硝酸铵**：有毒、可燃可爆。
   【红线】不自制、不大量储存、不与可燃物混放；
   【医疗红线】吸入后立即脱离现场、保持呼吸道通畅、尽快送医，
   **本册不给任何药物与剂量**。
4. **石灰与草木灰（碱性物质）**：可致皮肤与眼睛灼伤。
   【红线】拌灰与撒灰时**戴护目与口罩、站在上风向**，避免扬尘入眼入肺。
5. **硫酸与磷矿加工**：见册 17 与化工 01 的危化品红线；
   **磷矿可能伴生重金属（如镉）与放射性物质**，
   【判据】不明来源的磷矿**先不用**，长期施用会在土壤中累积。
6. **硝石管制**：既是肥也是火药原料，
   【红线】不大量囤积、不私下交易、不对外说是"硝"（见册 18、经济 07）。
7. **不得在缺资料的情况下试制现代农药**：
   农药属另一册内容（L22 综合植保），**本册不给任何农药配方、浓度与安全间隔期。**

### 8. 故障排查表

| 现象 | 优先怀疑 | 先查什么 |
|---|---|---|
| 苗期发黄、矮小 | 缺氮 | 是否秸秆还田未配氮 → 补腐熟粪肥/豆科 |
| 生长旺盛却不结实 | 氮过多或磷钾不足 | 停氮 → 补草木灰与骨粉 → 查密度与光照 |
| 老叶叶尖焦枯 | 缺钾 | 施草木灰（干燥施、不混粪） |
| 根系弱、成熟晚、叶发紫 | 缺磷 | 骨粉（煅烧粉碎）+ 有机质 |
| 新叶发黄而叶脉绿 | 缺铁（多为偏碱或积水） | 先查排水与酸碱 → 再谈补铁 |
| 施肥后萎蔫 | 烧苗（渗透脱水） | 立即大量灌水稀释 → 以后分次少量 |
| 土壤板结、开裂 | 有机质低、长期单施化肥 | 停化肥 → 上堆肥与绿肥 → 减少耕翻次数 |
| 土面发白结晶 | 盐渍化 | 灌水洗盐 → 改种耐盐/绿肥 → 长期增有机质 |
| 地越种越酸 | 长期单施氮肥 | 少量多次施石灰 → 增有机质缓冲 |
| 沟渠发绿发臭 | 养分流失 | 分次少量 → 肥施根区 → 施肥区远离水体 |
