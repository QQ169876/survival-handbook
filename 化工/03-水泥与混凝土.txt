### 1. 这一层的价值：唯一能自己造的"石头"

【经验】砖要一块块烧，石头要一块块开采搬运，
而水泥是**唯一可以"浇"成任意形状的石头**——堤坝、码头、地基、拱券、
粮仓、水渠、炮台、厂房地面，全靠它。

【史实】罗马人用火山灰 + 石灰 + 骨料做出耐久的混凝土，
不少海工结构两千年后仍存；1824 年前后波特兰水泥（硅酸盐水泥）出现，
此后成为现代土建的基础材料。这些是明确的史实。

【经验】在科技树上，水泥排在 L11 而不是更早，是因为它有两条硬门槛：
**能烧到约 1450℃ 的窑**（与册 19 玻璃同级，甚至更高），
以及**能把熟料磨到很细的粉磨能力**（工艺 08 的机械能力）。
这两条没到位时，能做的最多是"石灰砂浆"，做不出真正的水泥。

【判据】判断你能不能上水泥，只看一件事：
**你能不能连续、稳定地把一批料烧到"烧结成块、表面有熔融光泽"的程度。**
能，就可以试；不能，就老老实实烧石灰。

### 2. 前置依赖与门槛

| 前置 | 来自 | 为什么必须有 | 最低判据 |
|---|---|---|---|
| 高温窑（约 1400~1500℃） | 册 16、册 19 | 熟料烧结 | 能稳定达到并维持该温度 |
| 石灰石与黏土/页岩原料 | 地质勘察 | 钙与硅铝的来源 | 能找到成分稳定的矿点 |
| 破碎与粉磨 | 工艺 08、册 16 | 生料细度决定反应完全程度 | 能磨到"手指搓不出颗粒感" |
| 燃料（煤/焦/大量木柴） | 化工 01、册 16 | 煅烧最吃燃料 | 有持续供应，成本算得过来 |
| 度量与记录 | 工艺 05、经济 02 | 配比 | 体积与重量都能量 |
| 骨料（砂、石）与水源 | 分册 03 | 混凝土七成是骨料 | 砂含泥少、水洁净 |

【经验】最容易被低估的是**燃料账**。水泥是典型的"燃料换材料"产业：
每产一份水泥，要烧掉可观的燃料。
【判据】动手前先算：附近有没有煤？木炭路线能不能撑住？
**燃料成本算不过来，就先做石灰与三合土。**

### 3. 原理：石头怎么变回石头

【科学】石灰的循环（先弄懂这条，其余都是它的延伸）：
石灰石（碳酸钙）→ 煅烧 → 生石灰（氧化钙）+ 二氧化碳；
生石灰 + 水 → 熟石灰（氢氧化钙，放热、体积膨胀）；
熟石灰 + 空气中的二氧化碳 → 碳酸钙（**回到石头**）。
【经验】这就是石灰砂浆"会变硬"的全部秘密——**它靠空气里的二氧化碳慢慢变回石头**，
所以厚墙体内部几百年都不硬化，且**它不耐水**。

【科学】水硬性（水泥的关键差异）：
如果原料里除了钙还有**硅、铝**，煅烧后生成的不是纯氧化钙，
而是**硅酸钙等矿物**，它们能与水反应生成坚硬的水化物——
**这个反应不需要空气，甚至可以在水下进行。**
【判据】"能不能在水里硬"是水泥与石灰的分水岭，也是最简单的判别试验：
把一小团试样放在水里，能硬化就是水硬性的。

【科学】水化不是"干燥"，是**化学反应**。
水泥加水后形成凝胶与晶体，把骨料黏结成一个整体。
【经验】三条由此而来的铁律：
1. **不能让它干得太快**——水化需要水，干了水化就停了，强度也停了；
2. **不能冻**——水结冰膨胀会把早期结构撑坏；
3. **不能缺水养护**——早期（头几天到头几周）保湿是强度的一半。

### 4. 路线图：四级台阶

**第 1 级：石灰与石灰砂浆（先做，立刻有用）**
- 做法：石灰石入窑煅烧 → 生石灰 → 消化（浇水，放热，须小心）→ 熟石灰 →
  与砂调成砂浆。
- 【判据】消化完全（无"过烧"硬粒）、砂浆可塑、硬后不粉化。
- 【经验】加**火山灰质材料**（火山灰、煅烧黏土、稻壳灰、碎砖粉一类）
  能让石灰获得一定的水硬性与耐水性——【史实】这正是罗马混凝土的思路。
  【判据】掺与不掺各做一块试块，泡水后比较，能硬住的那个配方才是有效的。

**第 2 级：水硬性石灰 / 天然水泥**
- 【史实】含泥质的石灰石直接煅烧，产物天然带水硬性，
  19 世纪前被广泛使用，是波特兰水泥的前身。
- 【判据】烧出的料磨细后**加水能在水中硬化**，即成功。
- 【经验】这是"地质运气"：不是每个矿点都行。
  【判据】先在矿点取几块不同层位的样，小窑试烧，筛出能水硬的那一种——
  **这一步是本册性价比最高的动作**，做对了后面全顺。

**第 3 级：罗马式混凝土（推荐长期主力）**
- 配方思路（公开史料方向）：**石灰 + 火山灰质材料 + 骨料**，
  分层夯实（不是浇筑），用于墙体、地基、拱券、水池。
- 【经验】它的优点：烧成温度低（不用烧到烧结）、燃料省、
  耐久性好（史料为证）；缺点：早期强度低、需要时间。
- 【判据】试块一个月后能承受人踩不裂、泡水不散，即合格。

**第 4 级：波特兰水泥（真正的现代水泥）**
- 路线：石灰石 + 黏土按一定比例配料 → 磨细 → 煅烧至烧结（约 1450℃）
  → 冷却成熟料 → 与少量石膏同磨 → 水泥。
- 【经验】石膏的作用不是"调色"，是**调节凝结时间**——
  不加石膏的熟料粉加水会"急凝"，来不及施工就硬了。
- 【判据】三件事做成：
  1. 熟料**烧到出现熔融相、结块呈灰黑色**；
  2. 磨细后**加水能在水中硬化**；
  3. 凝结时间**够施工用**（不是一加水就硬）。

### 5. 混凝土：水泥 + 骨料 + 水 + 养护

【科学】混凝土的强度主要由**水灰比**（水与水泥的质量比）支配：
水越少（在能振捣密实的前提下）强度越高。
【经验】这是混凝土最重要的一句话——**多加水好施工，但会成倍地损失强度。**

【经验】体积配比的公开典型值（**现代工程常见做法，属公开工程资料；
现场须按骨料级配实测调整**）：
- 一般结构用混凝土常见体积比在 **水泥 : 砂 : 石 ≈ 1 : 2 : 3 ~ 1 : 2 : 4** 的量级；
- 砂浆常见 **水泥 : 砂 ≈ 1 : 2 ~ 1 : 3**（砌筑与抹面各取一端）；
- 水灰比通常控制在**能使拌合物"手握成团、落地散开"**的程度附近，
  【判据】以"能密实成型"为下限，不要为了好倒而多加水。
- **本册不给"某标号必须某配比"的说法**：骨料不同、水泥不同、含泥量不同，
  同一配比的结果可以差一倍。**试配 + 试块**才是唯一可靠的办法。

【经验】骨料的讲究（比配比更容易被忽视）：
- **级配**：大小颗粒搭配，小颗粒填大颗粒的空隙——
  空隙率越低，需要的水泥浆越少，强度越高、成本越低；
- **含泥量**：泥裹在骨料表面会阻断黏结，**是最常见的强度杀手**；
  【判据】砂抓一把加水搓，水浑浊就得洗；
- **针片状颗粒**多的碎石强度差，尽量用接近立方体的。

【经验】养护是本册最容易被跳过、也最值钱的一道工序：
- 【判据】浇筑后头七天**保持湿润**（覆盖湿草席/湿砂、勤洒水），
  烈日下要遮阳，霜期要保温；
- 【科学】水化在头几天最快，这时的保湿直接决定最终强度；
- 【经验】"混凝土浇完就不管"是新手最贵的错误——
  同一批料，养护与不养护，强度可以差一大截。

### 6. 判据：从原料到成品的九道关

| 环节 | 判据（做到了才算过） |
|---|---|
| 1. 选矿 | 石灰石敲开断面致密、遇稀盐酸剧烈起泡 |
| 2. 试烧 | 小窑试烧后加水能做水硬试验（水中硬化） |
| 3. 生料细度 | 手指搓不出明显颗粒；不同批次手感一致 |
| 4. 煅烧 | 熟料烧结成块、有熔融光泽、夹生率低 |
| 5. 磨细 | 同 3；越细反应越快，但过细不经济 |
| 6. 凝结 | 加水后不是立刻硬（可施工），也不是几天不硬 |
| 7. 试块 | 同配比做三块，7 天与 28 天各测一次（压或敲） |
| 8. 耐水 | 试块长期泡水不散不软（水硬性验证） |
| 9. 施工 | 振捣/夯实密实、无蜂窝麻面、养护到位 |

【经验】试块怎么做（没有压力机时的土办法）：
- 用同批料做**相同尺寸的小块**，养护到同龄期后，
  用"从同一高度落锤砸"或"加载重物直到破坏"做**相对比较**；
- 【判据】**比的是"新批次不低于留样的老批次"**，不是绝对值。
  这就足以支撑工程决策。

### 7. 故障排查

| 现象 | 原因 | 处理 |
|---|---|---|
| 砂浆/混凝土不硬化 | 石灰过多或烧不透；温度太低 | 重烧；保温；检查原料配比 |
| 一加水就急凝 | 缺石膏（熟料路线）；细度过高 | 掺配石膏同磨；调整细度 |
| 强度远低于试配 | 水加多了；含泥高；养护差 | 控水、洗砂、保湿养护 |
| 表面起砂、起粉 | 表面失水太快；水灰比大 | 遮阳、覆盖、收面后保湿 |
| 开裂（塑性收缩） | 失水快、无养护、气温高风大 | 覆盖保湿、避开正午浇筑 |
| 开裂（温度/干缩） | 构件过大无伸缩缝；养护不足 | 分段浇筑、设伸缩缝、延长养护 |
| 表面蜂窝麻面 | 未振捣/夯实；骨料级配差 | 加强捣实；改善级配 |
| 长期泡水软化 | 用的是气硬性石灰而非水硬性材料 | 走火山灰/水泥路线 |
| 试块一批好一批差 | 原料波动或计量不准 | 固定矿点与料仓，**每盘称量** |

### 8. 钢筋、模板与结构（决定成败的另一半）

【经验】混凝土抗压很好、**抗拉很差**（约为抗压的很小一部分）。
【科学】所以受拉的部位必须有钢筋——这就是钢筋混凝土。

【经验】钢筋（或代用）的三条：
1. **表面要干净**：锈皮、油污、泥都影响握裹；
   【判据】浮锈能擦掉即可用，成片剥落的锈要除净；
2. **要有足够的埋入与锚固长度**：钢筋是"被混凝土握住"才起作用的，
   握不住就白放；
3. **要有保护层**：钢筋离表面太近会先锈后胀、把混凝土崩开。
   【判据】用垫块（石块或砂浆块）把钢筋垫起来，不许直接贴着模板。

【科学】钢筋锈蚀是钢筋混凝土的头号病害：
锈的体积比铁大得多，会**从里面把混凝土胀裂**。
【经验】防的办法是**密实 + 足够保护层 + 避免氯盐**（海边、盐渍地、除冰盐）。
【红线】**绝不能用含氯的促凝剂/防冻剂去"提速"**——省几天，毁几十年。

【经验】模板与支撑：
- 模板要**不漏浆、不变形、能拆**；
- 支撑是**事故高发点**：混凝土自重很大，
  【判据】支撑必须验算（宁可多不可少）、地基要夯实垫板、
  **拆模顺序必须"后支的先拆、先支的后拆"**；
- 【红线】**强度未达龄期不得拆承重支撑、不得上荷载。**

【经验】结构常识三条（比配比更救命）：
1. **基础要落在好土上**：软弱土、回填土、冻土都不能直接做地基；
2. **拱与券必须有可靠的支座**：拱会向外推，支座不做够，拱必垮；
3. **开口（门窗洞）会显著削弱墙体**：洞口要设过梁，不要"留个洞再说"。

### 9. 安全红线

1. **生石灰消化（加水）是强放热反应，会沸腾喷溅，可致严重烧伤与失明。**
   【红线】消化必须在**耐热的敞开容器**中、**少量多次加水**、
   人要站在上风并**戴护目镜**；**绝不可把水一次倒进大量生石灰**，
   也**绝不可把脸凑近去看**。生石灰粉入眼**立即大量清水冲洗并送医**。
2. **水泥是强碱性**：湿水泥长时间接触皮肤会造成**化学灼伤**（不疼、延迟发作）。
   【判据】搅拌与浇筑穿长靴、戴手套，**收工后彻底清洗**；
   皮肤出现红肿灼痛立即冲洗就医。
3. **粉尘**：水泥与生料粉尘长期吸入损伤呼吸道；粉碎与装袋工序要湿式或通风，
   作业人员戴湿布口罩。**矽肺是不可逆的。**
4. **窑与高温**：与册 16、册 19 同级的窑火风险；
   出窑熟料即使表面变暗仍长时间高温，**冷却前禁止触摸与赤手搬运**。
5. **坍塌是土建的头号死因，不是机械。**
   - 【红线】**任何模板支撑未经验算不得浇筑**；
   - **拆模前必须有龄期与试块依据**，不许凭"看着硬了"；
   - 深基槽与基坑**必须放坡或支护**，
     【判据】土壁出现裂缝、渗水、掉块，立即撤人；
   - 拆除旧结构**从上往下**，不许掏底。
6. **有限空间**：仓、池、井内作业要先通风、要有监护人（见 L34 应急管理）。
7. 【红线】本册不给任何"加盐防冻""加氯促凝"的技巧——
   这类做法会毁掉结构，且危害在使用多年后才显现。
8. 【医疗红线】灼伤、眼伤、吸入性损伤的处置，**本册不给药物与剂量**：
   大量清水冲洗 → 脱离现场 → 尽快送医（见 医学/01）。
