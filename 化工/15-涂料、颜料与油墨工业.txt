      桐油、生漆、炭黑、矿物颜料、胶与蛋清，在别册已有做法。

先说结论（五条）：
  1. **涂料不是"一层颜色"，是一套三层系统**：
     **成膜物**（把大家粘住并连成膜）、**颜填料**（给颜色、遮盖、增稠、补强）、
     **助剂/介质**（让它能涂、能干、能存）。**改一层，另外两层跟着变。**
  2. **防腐的第一手段不是涂料，是让水不停留**（`冶金/03` 已定）；
     涂料只是"排水之后"的第二道。**顺序反了，刷得再好也白刷。**
  3. **涂层失败九成败在刷之前**：表面有锈、有油、有湿气、
     有松动的旧漆——**表面处理占七成**（`冶金/04` 同一结论）。
  4. **颜料与染料的分界是"溶不溶"**：染料溶进纤维或介质、
     靠分子着色；颜料是不溶的细颗粒、靠**遮盖与散射**。
     **所以细度与分散决定颜料的全部表现。**
  5. **重启期的正路是天然成膜物＋矿物/炭黑颜料**：
     桐油、生漆、虫胶、骨胶、蛋清、石灰、炭黑、赭石、石青，
     加研磨与留样对照。**合成树脂、铅白铬黄与溶剂型体系明确劝退。**

### 1. 这一层解决什么问题：给表面一层"能干的皮"

  【科学】涂层要同时干四件事：**隔水隔氧**（防腐）、
  **遮住底下的颜色**（遮盖）、**耐候耐磨损**（耐久）、
  **好看或好认**（标识）。四件事常常互相打架：
  膜厚了耐久但易开裂、颜料多了遮盖好但膜变脆、
  干得快好施工但流平差。**配方就是在这四者之间找折中。**

  【史实】涂层比化工早得多：生漆、桐油、大漆、蜡、
  蛋清与胶、石灰浆、矿物色浆，在古代东亚、地中海与欧洲
  各自成体系；19 世纪后随合成树脂、颜料工业与研磨设备成熟，
  才变成"按用途设计"的现代涂料工业。
  **这段史实说明：这一层不是"有了化工厂才有漆"，
  只是"有了化工厂才有稳定批次的漆"。**

  【经验】本册与相邻册的分工：`工艺/09 墨、油墨与装订`
  给了墨与炭黑的作坊做法、`化工/02 合成染料` 讲染料、
  `冶金/03 复合材料、涂层与防腐` 讲防腐体系与"失败九成在刷之前"、
  `冶金/04 表面处理` 讲前处理、`分册/12 造纸` 与 `分册/23 印刷`
  讲承印物与印刷。
  本册补的是"**当成吨的漆与墨要稳定量产时卡在哪**"，
  以及"作坊级怎么靠判据把天然漆做稳"。

### 2. 前置依赖与门槛

  | 前置 | 为什么必须有 | 缺了退到哪 |
  |---|---|---|
  | 成膜物（干性油、生漆、胶、蜡、树脂） | 膜的本体 | **退到桐油/生漆/胶，不造树脂** |
  | 颜填料（矿物、炭黑、土、白垩） | 遮盖、颜色、增稠 | 退到本地土与炭黑 |
  | 介质（水、油、少量溶剂） | 让它能涂开 | 优先水相与油相，**溶剂体系劝退** |
  | 研磨与分散（工艺/08、工艺/01） | 细度决定遮盖与着色 | 退到研钵/石磨＋静置沉降分级 |
  | 表面处理（冶金/04） | 附着力七成靠它 | **不处理就不涂** |
  | 留样对照与试板（工艺/16） | 判断耐候、遮盖、干燥 | 没有试板就不要上大面积 |
  | 通风、防尘与防火（安全/02/03） | 溶剂与粉尘 | 没有就不开线 |
  | 合成树脂与助剂工业（化工/04、分册/29） | 现代涂料的性能来源 | **明确劝退** |

  【经验】**门槛判据（三句话）**：
  1. 我要的是**防腐、标识、还是装饰**？
     防腐先排水（`冶金/03`），标识用颜色与形状就够，
     只有装饰才值得折腾色相。
  2. 表面**能不能先处理干净**？不能就别涂，
     **刷在锈与油上的漆一定掉**。
  3. 有没有**试板与留样**？没有对照，
     "这桶比上桶好"只是感觉。

### 3. 原理一：涂料三层体系（与冶金/03 合看）

  【科学】三层各司其职：

  | 层 | 干什么 | 出问题的样子 |
  |---|---|---|
  | 成膜物 | 从液态连成连续固膜、粘住底材与颜料 | 膜开裂、粉化、发黏不干、遇水发白 |
  | 颜填料 | 遮盖、给色、补强、调节稠度与成本 | 露底、浮色、沉淀结块、耐候褪色 |
  | 助剂/介质 | 分散、流平、干燥、防霉、储存稳定 | 流挂、刷痕、结皮、分层、长膜 |

  【科学】由此得到三条判据式结论：
  - **颜料与成膜物的比例有上限**：颗粒太多，
    没有足够的膜把它们包住，膜就粉化脱落；
  - **膜不是越厚越好**：厚膜内应力大、表里干得不一致，
    反而开裂起皱；**薄而多道，且每道干透**，比一道厚涂稳；
  - **底材与膜要"能伸能缩一起变"**：
    木、铁、石的胀缩不同，硬而脆的膜用在会动的底材上必裂。

  【经验】与 `冶金/03` 的合看结论：
  **排水 > 除锈 > 底漆 > 面漆**。
  前两道是"让它不泡水、让它抓得住"，
  后两道才是"给它一层皮"。**四道里前两道最便宜也最有效。**

### 4. 原理二：颜料与染料的分界

  【科学】一条判据分到底：**溶不溶**。

  | | 染料 | 颜料 |
  |---|---|---|
  | 溶解 | 溶于介质/纤维 | **不溶，以颗粒悬浮** |
  | 着色方式 | 分子吸附、结合 | 颗粒散射与吸收 |
  | 遮盖力 | 弱（透） | **强（能盖住底色）** |
  | 关键指标 | 亲和力、牢度 | **细度、分散、耐候** |
  | 手册位置 | `化工/02`、`分册/13` | 本册、`工艺/09` |

  【科学】颜料三件事：
  - **遮盖力**来自颗粒与介质的折射率差以及粒径；
    **磨得太细反而可能变透**（这是最反直觉的一条）；
  - **耐候**看它会不会与光、酸、硫、碱反应——
    许多鲜艳的矿物色会变黑或褪色；
  - **着色力**看细度与分散：**同一份颜料，
    分散开了能盖住的面积大得多**。

  【经验】作坊级可用的颜料来源（都不需要合成）：
  **炭黑**（油烟、炭，`工艺/09`、`化工/01`）、
  **土性与矿物色**（赭石、黄土、白垩、石青石绿一类）、
  **煅烧与焙烧改变色相**（`工艺/01` 窑火）、
  **植物色淀**（把植物染料沉到惰性粉上，
  `分册/13` 的媒染思路）。
  **含铅、含铬、含砷的鲜艳颜料一律不碰**（红线第 4 条）。

  【存疑·已说明】"颜色越鲜艳越好"不成立：
  历史上最鲜艳的几种恰恰毒性最高，
  且不少会与空气中硫化物反应变暗。
  **把"耐候与无毒"排在"鲜艳"前面**，是选材的第一课。

### 5. 原理三：成膜的三种方式（只写原理）

  【科学】液体变固体，只有三条路：

  | 方式 | 原理 | 判据式的理解 |
  |---|---|---|
  | **氧化聚合** | 干性油与空气中的氧慢慢交联成膜 | **靠天吃饭**：湿冷就慢、表干里不干 |
  | **挥发干燥** | 介质跑掉，剩下的成膜物留下 | 快、但**溶剂/水走了膜就薄**，且易燃或怕冻 |
  | **反应固化** | 两组分混合后化学交联 | 性能最好，但**配错比例就永远不干或发脆** |

  【科学】由此得到三条最实用的判断：
  - **"表干"不等于"干透"**：手摸不黏时里层可能还软，
    **叠涂太早必起皱、必咬底**；判据是指甲轻划不留白痕且无黏感，
    再留足间隔（同 `可信度说明` 的"判据优先于配方"）；
  - **温湿度是配方的一部分**：同一桶漆，
    梅雨天与干冷天表现完全不同，**所以必须有试板**；
  - **交联过头会变脆**：膜越硬越不耐底材变形，
    **"硬"不等于"耐久"**（`冶金/02` 的失效分析同一课）。

  【史实】现代合成树脂（醇酸、环氧、聚氨酯、丙烯酸一类）
  把"干燥速度、硬度、耐候、耐化学"分别做成可调变量，
  这是 20 世纪涂料工业的主线。
  **本册只承认这条史实，不给任何树脂合成路线、
  催干剂、固化剂配比与溶剂体系**——
  它们吃 `化工/04` 的整条石化链，重启期属劝退级。

### 6. 原理四：油墨为什么另立一册

  【科学】油墨同样是"颜料＋连接料＋助剂"，
  但它多四条苛刻约束，所以不能拿漆来凑：

  - **细度极细**：颗粒粗了会堵版、糊网点、划伤版与承印物；
  - **流变要对**：太稀会铺开洇墨、太稠会不下墨，
    **要"静止时稠、一压就流"**（这一条与 `工艺/06` 油脂的稠度直觉不同）；
  - **干燥要跟得上承印物**：纸吸墨、金属与塑料不吸，
    **同一支墨换承印物就换一套干燥逻辑**；
  - **不能伤版、不能透背、不能掉色**：
    印上去还要耐摩擦、耐光，且不能有刺鼻残留
    （`工艺/09` 已给装订与耐久那一课）。

  【经验】作坊级正路就是 `工艺/09` 与 `分册/23`：
  **油烟炭黑＋胶/油连接料＋研细＋试印**。
  四步都能靠留样与试印判断，不需要任何合成树脂。
  **判据是"印出来清不清楚、干后蹭不蹭手、放一季褪不褪色"**，
  不是配方表上的数字。

  【存疑·已说明】"墨越黑越浓越好"不成立：
  连接料不足的浓墨会掉粉、堵版、透背；
  **墨是"颜料与连接料的平衡"，不是"颜料越多越好"**
  （与第 3 节"颜料有上限"同一结论）。

### 7. 原理五：研磨、分散与细度

  【科学】颜料出厂常是团聚的粉团，
  **研磨的目的不是把颗粒磨小，是把团聚打散并让成膜物包住每颗颗粒**。
  分散不匀的三宗罪：**着色力浪费、局部粗粒划伤、
  储存时沉降结块**。

  【经验】作坊级四步（可照做）：
  1. **先润湿**：少量连接料把粉调成糊，别一上来就加大量油水；
  2. **再研磨**：石磨/研钵少量多次，方向一致，别贪快；
  3. **静置沉降分级**：粗粒先沉，取上层细浆——
     **这是没有细度计时最有效的"分级"办法**；
  4. **试板/试印留样**：同一块板刷一半、试印一行，
     与上一批并排比遮盖、色相与蹭手程度（`工艺/16`）。

  【经验】三条判别：
  - **指腹捻开无颗粒感**（**戴手套、不入口、不长时间接触皮肤**）；
  - **涂在玻璃或白纸上看有无粗粒与条纹**；
  - **静置一天看沉不沉、结不结块**，
    结块能搅开的尚可，搅不开的整批降级。

### 8. 判据与故障排查

  【经验】**验收五判据（可照做，先做试板）**：
  - **附着力**：干透后用指甲/胶带在划格处试，
    成片剥落即表面处理没做够（**回 `冶金/04`**，别加漆）；
  - **遮盖**：同样道数能不能盖住底色，与留样并排比；
  - **干燥**：表干与实干分开记，隔多久能叠涂；
  - **耐候**：试板放室外一处、留一处室内，一季后并排比褪色与粉化；
  - **耐水**：滴水看发不发白、擦后回不回色。

  | 症状 / 现象 | 优先排查 | 说明 |
  |---|---|---|
  | 成片剥落、起皮 | **表面有锈/油/湿**、底材没处理 | 回前处理，不是漆的问题 |
  | 流挂、泪痕 | 一次太厚、太稀 | 薄而多道；**别靠"多刷几下"救** |
  | 刷痕重、流不平 | 太稠或干得太快 | 调介质、改温湿度，先做试板 |
  | 起皱、咬底 | 叠涂太早，里层未干 | **等干透**，下一道更薄 |
  | 泛白、遇水发白 | 膜亲水或没干透遇潮 | 记录天气，避雨避露施工 |
  | 表面发黏、久不干 | 油未氧化、湿冷、配比失衡 | 延长间隔、通风；**不靠加催干剂硬催** |
  | 粉化、掉粉 | 颜料过多、成膜物不足 | 减颜料、加连接料，先做小样 |
  | 浮色、发花 | 分散不匀或密度差大 | 重新研磨分散，见第 7 节 |
  | 桶内结皮、沉降硬块 | 储存进气、久放 | 结皮整块揭除不用；**硬块搅不开即降级** |
  | 褪色、变暗 | 颜料不耐光/与硫反应 | 换耐候颜料，**别靠罩一层清漆掩盖** |
  | 印迹糊、洇、透背 | 墨太稀或承印物不吸 | 调稠度、换纸、试印再上版 |
  | 蹭手掉色 | 连接料不足或未干透 | 回 `工艺/09` 的配墨与干燥判据 |

### 9. 路线图：五级台阶（台阶〇~二可落地）

  - **台阶〇 · 先排水、先处理表面（当天可做，收益最大）**：
    `冶金/03` 的四道顺序：改排水 → 除锈除油 → 才谈刷。
    **这一步不花钱，且拿走一半以上的防腐收益。**
  - **台阶一 · 天然成膜物与矿物色（第一周就做）**：
    桐油/生漆/胶/蜡＋炭黑/赭石/白垩，研磨润湿、
    试板留样、薄涂多道；**墨与色浆按 `工艺/09` 试印**。
  - **台阶二 · 分级、耐候与色相管理（作坊级）**：
    静置沉降分级、耐候试板、批次台账、
    按用途选耐候无毒颜料；**含铅铬砷鲜艳颜料一律排除**。
  - **台阶三 · 教学演示（只讲现象）**：
    氧化聚合、挥发、固化三种成膜方式，
    以及"表干≠实干""磨太细反而变透"两个反直觉现象；
    **任何树脂合成、溶剂型配漆、催干剂试验都不做**。
  - **台阶四 · 现代涂料与油墨工业（明确劝退）**：
    前置是合成树脂（`化工/04`、`分册/29`）、
    颜料工业、研磨分散设备、流变与耐候检测、溶剂回收与三废。
    **本册不提供任何走向它的配方、参数与操作步骤。**

### 10. 安全红线

  1. **一律不给树脂合成、催干剂、固化剂配比、
     溶剂体系、研磨参数与色浆处方**。
  2. **含铅（铅白）、含铬（铬黄）、含砷等传统鲜艳颜料
     一律不碰、不磨、不用**：粉尘与皮肤接触均可致中毒，
     **尤其不得用于食器、玩具、儿童可触及处与室内**
     （`安全/03`、`环境/02`）；来源不明的旧颜料按危废隔离。
  3. **溶剂与干性油**：多数溶剂极易燃、蒸气有毒且比空气重；
     **通风、禁火、禁明火加热、不进有限空间**；
     油布/油棉纱**摊开晾干、不得成堆堆放**（可自热自燃，
     `安全/02`）；废溶剂不倒水体土壤（`环境/02`）。
  4. **生漆与天然树脂**：可引起严重皮肤过敏，
     **戴手套、护眼、通风，沾到立即清洗；不徒手试"过不过敏"**。
  5. **粉尘**：矿物颜料、白垩、炭黑细粉吸入有害，
     研磨须防尘护呼吸，**不在有明火处筛粉**。
  6. **表面处理中的酸洗与除锈**：强酸灼伤按大量清水冲洗就医，
     **不作酸碱中和尝试**；酸洗可能放出氢气，禁火
     （`冶金/04`、`化工/05`、`化工/10`）。
  7. **不尝味、不入口、不用皮肤长时间接触任何待测物料**；
     未知整桶物料按最高风险隔离，交专业处置。
  8. **密闭空间刷漆/烘干一律不做**（缺氧与溶剂积聚，
     `安全/03`）；**绝不在密闭系统里加热**。
  9. **医疗内容本册不涉及**；全书一律不给剂量。野生菌一律不采不食。
 10. **涂料、颜料与危化品的合规要求以当地现行规定为准**：
     `法律/06~10`。
