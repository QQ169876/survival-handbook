### 1. 结论先行：材料不是选出来的，是被工况选出来的

【判据】先把三句话摆出来，它们是本册的全部：

1. **没有"好材料"，只有"对这个工况合适的材料"。**
   【经验】最硬的材料往往最脆；最耐蚀的材料往往最贵最难加工；
   最好的弹簧钢拿来当刀刃会崩，最好的刀刃钢拿来当弹簧会断；
2. **同样的钢，热处理不同就是不同的材料。**
   【科学】这是本册最反直觉也最重要的一条：
   **成分决定"它能变成什么样"，热处理决定"它实际上是什么样"**；
3. **坏了的东西会说话，但你得会听。**
   【判据】断口、磨痕、变形、颜色——
   **它把失效原因写在自己身上，多数人只是没看**（见 `工艺/18`）。

【判据】因此本册的顺序是：
**先看它怎么坏的 → 再反推需要什么性能 → 最后才选材料与工艺。**
顺序反了，就会陷入"换更贵的材料还是照样坏"的循环。

### 3. 原理一：结构—性能—工艺三角

【科学】材料学的基本关系是三角：

- **结构**（原子怎么排、晶粒多大、有什么相、有什么缺陷）；
- **性能**（强度、硬度、韧性、塑性、耐蚀、导电、导热、耐磨）；
- **工艺**（怎么炼、怎么铸/锻/轧、怎么热、怎么冷、怎么表面处理）。

【判据】这条三角的含义是：
**你不能直接买"性能"，只能通过"控制结构与工艺"去得到它。**
→ 【经验】所以在没有化验能力的年代，**你真正能控制的是工艺**，
而工艺的效果**只能靠试片与试验来验证**（见 `化工/05` 的试块、`可信度说明.md` 的小试）。

【科学】几个必须知道的结构概念：
- **晶粒**：金属是多晶体，由大量小晶粒组成；
  【判据】**晶粒细化通常同时提高强度与韧性**——
  这是少数"两样都变好"的手段，因此极受重视；
- **相**：同一材料里成分或结构不同的区域（如钢里的铁素体、渗碳体、奥氏体、马氏体）；
- **缺陷**：位错、夹杂、气孔、偏析——
  【判据】**失效几乎总是从缺陷处开始**，这就是为什么**冶炼纯净度与铸造质量**那么关键
  （见 `冶金/01`）。

### 4. 原理二：五种失效方式，各有各的长相

【判据】这一节是本册最该背下来的一节。**先认失效模式，再谈材料。**

| 失效方式 | 怎么发生 | 长什么样 | 对策方向 |
|---|---|---|---|
| **过载** | 一次受力超过承载能力 | 明显变形、一次性断裂 | 加大截面、换更强材料、减小载荷 |
| **疲劳** | 反复受力，裂纹慢慢长，最后突然断 | **断口常有一片光滑的"海滩纹"区 + 最后粗糙的瞬断区**；**几乎没有整体变形** | 降应力、去尖角、改善表面、避免应力集中 |
| **磨损** | 相对运动把材料一点点磨掉 | 尺寸变小、表面光亮或有犁沟 | 提高硬度、改善润滑、改成可更换的易损件 |
| **腐蚀** | 与环境化学反应 | 锈层、点蚀坑、变色、壁厚减薄 | 换材料、隔离环境、涂层、牺牲阳极 |
| **蠕变** | 高温下长期受力，慢慢变形 | **高温件的缓慢伸长、下垂、鼓包** | 降工作温度、换耐热材料、缩短寿命期 |

【判据】最需要强调的三条：

1. **疲劳是最会骗人的。** 【经验】**它断之前没有任何变形、没有任何预兆，
   而且断在应力远低于"一次拉断"的水平**。
   → 【判据】**凡是反复受力的件（轴、弹簧、连杆、齿轮、吊具、链条、弹簧片），
   一律按疲劳设计，不按静强度设计**；
2. **应力集中是疲劳的帮凶。**
   【科学】**裂纹从几何突变处开始**——尖角、孔、螺纹根部、刀痕、划伤、焊缝咬边。
   → 【经验】**把尖角改成圆角、把刀痕磨掉、把焊缝打磨平，
   这三件"不要钱"的事，常常比换材料更管用**；
3. **腐蚀与疲劳会联手**（腐蚀疲劳）、**磨损与腐蚀会联手**（磨蚀）——
   【判据】**两个机制叠加时，寿命不是相加，是相乘地缩短。**

### 5. 原理三：材料谱系与"什么时候不该用金属"

【判据】按"什么时候该想到它"排队，比按"强度排序"有用：

- **钢铁**：【经验】**默认选项**。便宜、强度高、能热处理、能焊、能切削、到处都有废钢；
- **铸铁**：【判据】**抗压好、耐磨、减震、易铸造，但脆、不能锻**。
  → 机床床身、缸体、井盖、配重——**这些地方它是首选**；
- **铜及铜合金**：【科学】导电导热极好、耐蚀、易加工、但不耐磨且贵。
  → 电气、换热、轴承衬、管件（见 `工艺/04`、`电力/04`）；
- **铝及铝合金**：【判据】轻、耐蚀、**但强度与耐热远不如钢，且不能靠火花认**。
  → 需要轻、需要耐蚀、不承大力的场合；
- **陶瓷与耐火材料**：【科学】硬、耐高温、耐腐蚀、**但极脆、怕热震**。
  → 炉衬、坩埚、刀具、绝缘（见 `工艺/01`）；
- **木材**：【判据】**在重启情境里被严重低估**——
  比强度不差、易加工、可更换、吸震、不导电、不怕某些腐蚀（见 `工艺/12`）；
- **高分子与橡胶**：弹性、密封、绝缘、耐蚀，但**怕热、怕紫外线、会老化**，
  【经验】**老化是它最主要的失效方式，且常常是"放着不用也在坏"**；
- **复合材料**：【科学】把两种材料组合，拿到两者都没有的性质
  （如"钢筋 + 混凝土"、"麻刀 + 灰泥"、"纤维 + 树脂"）。
  【判据】**这是最古老也最有效的一招，不一定是高科技**（见 `化工/05`）。

【判据】"什么时候不该用金属"的四条：
1. 需要**绝缘**时；
2. 需要**耐强酸强碱**而买不起特种合金时（考虑陶瓷、玻璃、搪瓷、橡胶衬里）；
3. 需要**耐高温又不承冲击**时（考虑耐火与陶瓷）；
4. **需要它自己润滑、自己吸震、易现场更换**时（考虑木材、皮革、纤维与聚合物）。

### 6. 原理四：热处理四把火，只写"它们在干什么"

【科学】钢的热处理核心在于：**加热时组织会变，冷却快慢会决定它变成什么。**
【判据】这是本册唯一必须记住的原理句：**冷却速度是热处理的真正变量。**

【科学】四把火，按目的说明（**一律不给温度、时间与介质配比**）：

1. **退火**：加热后**缓慢冷却**。
   【判据】目的：变软、好加工、消除内应力、细化或均匀化组织。
   → 【经验】**加工不动了、或加工完变形了，第一个该想到的就是它**；
2. **正火**：加热后在**空气中冷却**。
   【判据】目的：比退火稍硬稍强、组织更细更均匀，常作为后续的准备；
3. **淬火**：加热后**快速冷却**。
   【判据】目的：得到很硬很脆的组织。
   → 【经验】**淬火只是把硬度"存"进去，同时把内应力也存了进去**——
   **淬完不回火，等于把一件又硬又脆、随时会裂的东西放进机器**；
4. **回火**：淬火后再**加热到较低温度并保温后冷却**。
   【判据】目的：**把一部分硬度换成韧性，把内应力放掉**。
   → 【经验】**"淬火 + 回火"是一对，永远不要只做前一半**——
   这是外行最常犯的错。

【判据】三条必须知道的补充：
- **截面越大，心部冷得越慢**：【经验】**大件淬不透，表面硬心部软**——
  这是"同样一把刀，小刀好用大刀软"的原因之一；
- **形状越复杂越容易裂**：【科学】冷热不均造成内应力，
  → 【经验】**尖角、厚薄突变、孔边是开裂的高发处**；
- **脱碳与氧化**：【判据】加热时表面会失碳、会起皮，
  → 【经验】**表层失碳会让"淬了火却不硬"**，
  加工时要留余量，或在条件允许时保护表面。

【判据】本册明确说明：
**所有加热温度、保温时间与冷却介质，一律以本地试片实测为准**（第 11 节）。
**不参考任何现成数值表**——因为你的材料成分不明、炉子不均、测温也不准。

### 7. 原理五：表面与心部——渗碳、渗氮与表面淬火的思路

【判据】很多零件要的不是"整体都硬"，而是**"表面硬、心部韧"**——
齿轮、轴、凸轮、销、链条件都是这样。这条矛盾怎么解决？三条思路：

1. **表面淬火**：【科学】**只加热表层再快速冷却**，心部不受影响。
   【判据】特点是**心部保持原有韧性**，且变形相对小；
2. **渗碳（及类似的渗入）**：【科学】在含碳环境中加热，
   **让碳渗进表层**，然后再淬火——**表层变成高碳钢，心部还是原来那样**。
   【判据】这是一条"**改表面成分**"的路线，效果好但需要**可控的渗剂与炉气**；
3. **渗氮及类似**：【科学】让氮渗入表层形成很硬的化合物层。
   【判据】它通常**温度更低、变形更小**，但**层薄、且需要专门的工艺条件**。

【判据】本册立场：
**这三条都属于"能理解、能判断，但在重启情境里很难稳定复现"的一类。**
【经验】实用替代办法反而是这几条：
- **用低碳钢 + 表面淬火**解决一部分；
- **用"可更换的耐磨件"**代替"整体耐磨"（见 `工艺/13` 的易损件思路）；
- **用镶套、堆焊、镶钢口、冷硬铸铁**这类**局部强化**的老办法；
- **实在要耐磨又做不了热处理时，用"厚一点 + 可换 + 勤检查"来换寿命。**

### 8. 原理六：硬度、韧性与"硬不等于好"

【科学】**硬度**是"抵抗压入与划伤的能力"，
**韧性**是"断裂前吸收能量的能力"，**强度**是"抵抗变形与破坏的能力"。
【判据】三者常常互相冲突——这就是所谓"折中"。

【经验】土办法的判别（**只给相对比较，不给换算表**）：
- **锉刀试**：【判据】**锉刀打滑 = 硬；锉得动 = 软**。
  这是现场最实用的一招，**但会留下伤痕，只能用于非关键面**；
- **互划**：用已知的东西划未知的，排出软硬顺序；
- **敲击与弹性**：【经验】**回弹高、声音清脆**往往对应高硬度与高弹性；
- **弯折试验**：【判据】**弯得动 = 塑性好；一弯就断 = 脆**；
  【经验】**做一个"弯了不折断"的样品，往往是判断韧性最直观的办法**。

【判据】四条常被搞混的地方：
1. **硬 ≠ 耐磨**（耐磨还取决于组织、润滑与配对材料）；
2. **硬 ≠ 强**（很硬的东西可以很脆，一冲击就碎）；
3. **软 ≠ 差**（密封、垫片、轴瓦就是要软，见 `工艺/11`）；
4. **"更硬"常常意味着"更难的加工"**——
   【经验】**先问"我有没有能加工它的工具"**，
   `工艺/03` 说过：**工具比工件更硬，才谈得上加工**。

### 9. 路线图：五级台阶（台阶一、二立刻可做）

**台阶一 · 认材料、认失效（立刻做）**
- 建立**"材料角"**：把已知来源的钢、铁、铜、铝各存一块，打标记当对照样；
- 火花、断口、磁性、密度、锉刀——**五招练熟**；
- 【判据】**给每一个坏掉的件拍照片、留断口、写一句"它怎么坏的"**——
  这份档案的价值高于材料本身（见 `工艺/19`）。

**台阶二 · 退火、正火与简单淬火回火（有炉有耐火就行）**
- 需要：能到温的炉（见 `工艺/01` 的耐火与 `化工/05` 的窑）、
  测温手段、**安全第一**；
- 【经验】**先拿试片做，不拿成品做**——
  **同炉放几块不同处理的试片，处理后逐块锉、弯、打断、看断口**；
- 【判据】**先追求"每次一样"，再追求"和书上一样"**——
  重复性是这一层唯一可依靠的东西（见 `工艺/16`）。

**台阶三 · 稳定的淬火回火与局部强化（需要测温、介质与经验）**
- 【判据】**能稳定重复，才能谈性能**；
- 表面淬火、镶套、堆焊代替整体渗碳；
- 【经验】**把"每件都做记录"变成纪律**：材料来源、加热、冷却、硬度表现、
  使用结果——**这是你自己的材料手册**。

**台阶四 · 合金化与受控气氛（需要化验与工业气体）**
- 【判据】**没有化验就没有材料，只有"看起来是钢的东西"**
  （与 `化工/04` 那句"没有化验就没有产品"完全同构）；
- 到这一级就明确依赖现代工业。

**台阶五 · 新材料开发（明确劝退）**
- 【经验】**开发一种新合金的周期以十年计，且需要全套试验能力**；
- 【判据】**在重启情境里，正确的做法是"用现有的、用能修的、用能换的"**，
  而不是"造更好的"。

### 10. 为什么做不出来：五道门槛

1. **成分不可知**：【判据】**你不知道废钢里有什么**——
   合金元素、有害残余元素、来历不明的镀层与夹杂物；
   → 【经验】**这是废钢路线的固有代价**（见 `冶金/01`）；
2. **温度测不准、炉子不均**：
   【判据】**热处理的变量是温度与时间，而这两样恰恰最难在没有仪表时控制**；
3. **没有金相与硬度手段**：
   【经验】**看不见组织、量不了硬度，就只能靠打断——而打断是破坏性的**；
4. **介质与耗材**：淬火油、盐、渗剂、保护气氛——
   【判据】**有的是消耗品，有的本身有毒有害**（见红线）；
5. **一致性**：【经验】**做出一把好刀不难，做出一百把一样好的刀极难。**

【判据】这五条的现实含义：
**把力气花在"认材料、认失效、会退火、会回火、会做试片"上，
回报远高于追求高硬度。**

### 11. 判据与故障排查：坏了的东西怎么读出原因

【判据】拿到一个坏件，按这个顺序看（**每一步都要拍照记录**）：

1. **先看变形**：有明显弯、扭、拉长 → **过载**；
   几乎没有变形 → **疲劳或脆性断裂**（这是第一个分岔口）；
2. **再看断口**：
   - **有海滩纹/贝壳纹 + 最后粗糙区 → 疲劳**；
   - **平齐发亮、呈结晶状 → 脆性断裂**；
   - **纤维状、暗灰、有拉长 → 韧性断裂**；
   - **有陈旧色（先前的裂纹面已经氧化） → 裂纹早就有了，是慢慢长到断的**；
3. **找起点**：【经验】**裂纹起点总在表面或缺陷处**——
   尖角、刀痕、孔边、夹渣、腐蚀坑、焊缝；
4. **看表面**：磨损痕、腐蚀坑、氧化色、脱碳层、镀层剥落；
5. **看配对件**：【判据】**坏的不是一件，是一对**——
   轴坏了要看瓦，齿轮坏了要看它的搭档；
6. **问历史**：【经验】**什么时候坏的、坏了几次、换过什么、
   润滑没有、有没有改过用途、有没有超负荷**——
   **这六问常常比看断口更快给出答案**；
7. **做对照**：拿一个**没坏的同类件**比一比——
   【判据】**差别在哪里，多半就是原因所在**（见 `工艺/16` 的对照）。

【判据】热处理失败的快速判据：

| 现象 | 最可能 |
|---|---|
| 淬了火不硬 | 表面脱碳、冷却不够快、材料本身碳不足 |
| 淬完开裂 | 冷得太急、形状有尖角/厚薄突变、**没及时回火** |
| 用着突然断 | **没回火或回火不足**（内应力还在） |
| 变形很大 | 加热不均、装炉方式不对、冷却不均 |
| 软硬不匀 | 炉温不均、截面太大淬不透、材料成分不匀 |
| 加工不动 | 该退火的没退火（或硬度本来就超出你的刀具能力） |

### 12. 安全红线

1. **绝不用自制或来源不明的热处理件做安全件**——
   制动件、承压件、承重件、吊装件、弹簧、链条、车辆与航空件
   （见 `工艺/13`、`机械/01`、`电力/03`）；
2. **淬火油是火灾隐患**：【判据】**油槽必须有盖、有排气、远离明火、
   备灭火手段、不得用水灭油火**（见 `化工/04` 的闪点红线）；
3. **绝不加热密闭容器与来路不明的金属件**——
   残留液体、密闭腔体、镀层与放射源都可能致命（见 `电力/07`、`工艺/19`）；
4. **盐浴与渗剂中的氰化物、铅、钡盐 historically 被使用过**：
   【判据】**氰化物可经皮肤与呼吸道致死，是这一类工艺里最危险的东西**——
   【经验】**遇到不明盐类残渣一律按剧毒处理：不碰、不扬尘、不通下水道、隔离上报**；
   **本册不给任何配方，也不建议任何人在重启情境里触碰这一类工艺**；
5. **酸洗与除锈的酸必须管理**：【经验】**酸 + 金属会放出氢气**，
   **氢气聚集 + 明火 = 爆炸**（见 `化工/04`、`分册/17` 的酸与氢气红线）；
6. **磨削与打磨必须护眼、防火、通风**：金属粉尘有害，
   **含铅、铬、镍、锰、铍的合金粉尘尤其**（见 `工艺/04`、`冶金/01`）；
7. **高温作业的烫伤与热辐射**：【经验】**"看着不红"不等于不烫**——
   热处理件在没有明显变色时仍可造成严重烫伤；
8. **不得把不合格件"回炉重来"无限次**：
   【判据】**反复加热会加重脱碳、氧化与晶粒粗化**——
   **重来有次数上限，且要记录**；
9. **不得把"看起来一样"的废钢当同一批用**：
   【经验】**混料是这一层最昂贵的错误**，它让所有试验结果都失去意义；
10. **不得在通电设备、易燃物与密闭空间旁做热处理**；
11. **现实中的承压设备用钢、焊接工艺与热处理均受标准与法律管制**
    （见 `法律/06~10`），本册不构成任何现实中的材料与工艺依据。
