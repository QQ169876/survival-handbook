# 甲部 · 原典原文

## 一、天工开物·墨（丹青第十六）

凡墨，烧烟凝质而为之。取桐油、清油、猪油烟为者，居十之一，取松烟为者，居十之九。凡造贵重墨者，国朝推重徽郡人，或以载油之艰，遣人僦居荆、襄、辰、沅，就其贱值桐油点烟而归。其墨他日登于纸上，日影横射有红光者，则以紫草汁浸染灯心而燃炷者也。

凡爇油取烟，每油一斤，得上烟一两余。手力捷疾者，一人供事灯盏二百副。若刮取怠缓则烟老，火燃质料并丧也。其余寻常用墨，则先将松树流去胶香，然后伐木。凡松香有一毛未净尽，其烟造墨，终有滓结不解之病。凡松树流去香，木根凿一小孔，炷灯缓炙，则通身膏液，就暖倾流而出也。

凡烧松烟，伐松斩成尺寸，鞠篾为圆屋如舟中雨篷式，接连十余丈。内外与接口皆以纸及席糊固完成。隔位数节，小孔出烟，其下掩土砌砖先为通烟道路。燃薪数日，歇冷入中扫刮。凡烧松烟，放火通烟，自头彻尾。靠尾一，二节者为清烟，取入佳墨为料。中节者为混烟，取为时墨料。若近头一，二节，只刮取为烟子，货卖刷印书文家，仍取研细用之。其余则供漆工、垩工之涂玄者。

凡松烟造墨，入水久浸，以浮沉分清悫。其和胶之后，以捶敲多寡分脆坚。其增入珍料与漱金、衔麝，则松烟、油烟增减听人。其余《墨经》、《墨谱》，博物者自详，此不过粗纪质料原因而已。

## 二、齐民要术·卷九·煮胶第九十

【煮胶法】

煮胶要用二月、三月、九月、十月，余月则不成。（注：热则不凝，无作饼。寒则冻瘃，令胶不黏。）沙牛皮、水牛皮、猪皮为上，驴、马、驼、骡皮为次。（注：其胶势力，虽复相似，但驴、马皮薄毛多，胶少，倍费樵薪。）破皮履、鞋底、格椎皮、靴底、破鞍、靫，但是生皮，无问年岁久远，不腐烂者，悉皆中煮。（注：然新皮胶色明净而胜，其陈久者固宜，不如新者。）其脂肕、盐熟之皮，则不中用。（注：譬如生铁，一经柔熟，永无镕铸之理，无烂汁故也。）唯欲旧釜大而不渝者。（注：釜新则烧令皮著底，釜小费薪火，釜渝令胶色黑。）

法：于井边坑中，浸皮四五日，令极液。以水净洗濯，无令有泥。片割，著釜中，不须削毛。（注：削毛费功，于胶无益。）凡水皆得煮；然咸苦之水，胶乃更胜。长作木匕，匕头施铁刃，时时彻底搅之，勿令著底。（注：匕头不施铁刃，虽搅不彻底，不彻底则焦，焦则胶恶，是以尤须数数搅之。）水少更添，常使滂沛。经宿晬时，勿令绝火。候皮烂熟，以匕沥汁，看末后一珠，微有黏势，胶便熟矣。（注：为过伤火，令胶焦。）取净干盆，置灶埵（注：丁果反）上，以漉米床加盆，布蓬草于床上，以大杓挹取胶汁，泻著蓬草上，滤去滓秽。挹时勿停火。（注：火停沸定，则皮膏汁下，挹不得也。）淳熟汁尽，更添水煮之；搅如初法。熟复挹取。看皮垂尽，著釜焦黑，无复黏势，乃弃去之。

胶盆向满，舁著空静处屋中，仰头令凝。（注：盖则气变成水，令胶解离。）凌旦，合盆于席上，脱取凝胶。口湿细紧线以割之。其近盆底土恶之处，不中用者，割却少许。然后十字坼破之，又中断为段，较薄割为饼。（注：唯极薄为佳，非直易干，又色似琥珀者好。坚厚者既难燥，又见黯黑，皆为胶恶也。）近盆末下，名为「笨胶」，可以建车。近盆末上，即是「胶清」，可以杂用。最上胶皮如粥膜者，胶中之上，第一黏好。

先于庭中竖槌，施三重箔樀，令免狗鼠，于最下箔上，布置胶饼，其上两重，为作荫凉，并扞霜露。（注：胶饼虽凝，水汁未尽，见日即消；霜露沾濡，复难干燥。）旦起至食时，卷去上箔，令胶见日；（注：凌旦气寒，不畏消释；霜露之润，见日即干。）食后还复舒箔为荫。雨则内敞屋之下，则不须重箔。四五日浥浥时，绳穿胶饼，悬而日曝。

极干，乃内屋内，悬纸笼之。（注：以防青蝇尘土之污。）夏中虽软相著，至八月秋凉时，日中曝之，还复坚好。

## 三、齐民要术·卷九·笔墨第九十一

【笔法】

韦仲将《笔方》曰：「先次以铁梳梳兔毫及羊青毛，去其秽毛，盖使不髯。茹讫，各别之。皆用梳掌痛拍整齐毫锋端，本各作扁，极令均调平好，用衣羊青毛——缩羊青毛去兔毫头下二分许。然后合扁，卷令极圆。讫，痛颉之。」

「以所整羊毛中截，用衣中心——名曰『笔柱』，或曰『墨池』、『承墨』。复用毫青衣羊青毛外，如作柱法，使中心齐，亦使平均。痛颉，内管中，宁随毛长者使深。宁小不大。笔之大要也。」

【合墨法】

好醇烟，捣讫，以细绢筛——于堈内筛去草莽若细沙、尘埃。此物至轻微，不宜露筛，喜失飞去，不可不慎。墨一斤，以好胶五两，浸梣（注：才心反）皮汁中。梣，江南樊鸡木皮也；其皮入水绿色，解胶，又益墨色。可下鸡子白——去黄——五颗。亦以真珠砂一两，麝香一两，别治，细筛，都合调。下铁臼中，宁刚不宜泽，捣三万杵，杵多益善。合墨不得过二月、九月，温时败臭，寒则难干潼溶，见风自解碎。重不得过三二两。墨之大诀如此。宁小不大。

# 乙部 · 油墨、装订与质量判据（整理编写，非古籍原文）

## 四、三份原典各说了什么（串讲）

【经验】把三份原典放在一起读，会得到一条完整链条：

- 《齐民要术·煮胶》给的是**胶**——墨的黏结剂，也是装订的糨糊基料；
- 《齐民要术·合墨法》给的是**配方与工序**：烟 + 胶 + 添加剂 + 三万杵；
- 《天工开物·墨》给的是**产业视角**：松烟占九成、油烟占一成，
  取烟的窑怎么搭、烟怎么按窑内位置分三等、一人能管多少盏灯。

【经验】这一层在科技树上的真正位置是：**它是"知识可复制"这条链的最后一块。**
纸（册 12）让记录成为可能，印刷（册 23）让复制成为可能，
而墨与装订决定复制品**能存多久、能不能翻得动**。
一本纸好、版好、墨差的书，五十年就糊；一本墨好、装好的书，能传到孙子手上。

【存疑】原典中的配比（墨一斤配胶五两、蛋白五颗、珠砂麝香各一两）：
古今斤两标准不一、胶的纯度不一、烟的粗细不一，
**照搬多半失败**。正确做法是把它当"结构"读：
**烟是主体，胶是黏结剂，少量添加剂调色与防裂，捶打决定质地**。

## 五、墨的原理：碳 + 胶 + 捶打

【科学】墨的本质是**极细的碳颗粒（炭黑）分散在胶里，干燥后成固体**。
- 碳提供颜色，且**化学性质极稳**——这是为什么千年古字画至今墨色如新；
- 胶把碳黏在一起、黏在纸上；胶太多则墨滞笔、易裂，太少则掉渣、不黑；
- 捶打（原书"捣三万杵"）的作用是**让碳与胶充分混合、排出气泡、使质地致密**。
  【经验】"杵多益善"这四个字是本册最实在的一条经验——
  没有机械的时代，唯一能保证均匀的办法就是多打。

【科学】为什么松烟与油烟不一样：
- 松烟：颗粒较粗、色偏冷蓝黑、覆盖力强，适合写字（字口清晰）；
- 油烟：颗粒更细、色偏暖、有光泽，适合印刷与绘画（层次好）。
  【史实】原书"取松烟为者居十之九"反映的是明末松烟为主的产业格局。

【经验】取烟的窑（原书"鞠篾为圆屋…接连十余丈"）为什么那样搭：
烟要**按窑内位置分级**——靠尾的清烟最好，中节混烟次之，近头只能做烟子。
【判据】分级不看位置看**颜色与手感**：越靠尾越细、越黑、越松软；
粗糙发灰发褐的是低等烟，只能刷印粗纸或做涂料。

【经验】一条最容易漏掉的纪律：**烟要"嫩"不要"老"。**
原书"刮取怠缓则烟老"——刮得不勤，火焰把已经凝下的烟又烧掉了。
【判据】勤刮、快刮，烟越勤取越细；取烟的人手要快，这跟榨油"疾倾疾裹"是同一个道理。

【经验】配料三条（按原典结构，不给新数字）：
1. 胶要**先化开、再和烟**，不可干混；
2. 加一点**防裂与调香的添加物**是传统做法（原典用蛋白、梣皮汁、麝香），
   但【存疑】其功效多为经验，且蛋白类易腐——**加了蛋白的墨要尽快用完或充分干燥**；
3. 【判据】和好的墨团"宁刚不宜泽"（宁可硬不要稀）：
   硬了可以再捶，稀了就废了。

## 六、油墨：为什么印刷的墨不是写字的墨

【科学】写字墨要"能在纸上停住、不洇"；印刷墨要"能均匀转移到版面、
再从版面均匀转移到纸、并快速固着"。两者的差别在三个参数：
- **黏度**：印刷墨更稠（像稀蜜），写字墨更稀（像水）；
- **颗粒**：印刷墨要求更细，否则堵版、糊字；
- **干燥**：印刷要求"印完就干"，否则一叠纸全粘住。

【经验】土法印刷油墨的调法（与册 23 印刷配套）：
- 基料：上等烟（油烟最好）；
- 连结料：**干性油（桐油）熬炼到一定稠度**是关键——
  桐油本身能氧化成膜，这正是"印完能干"的来源；
- 调整：太稠加少量清油，太稀加稠油或少量树脂（松香）；松香要**先炼熟**再用，
  生松香黏而发黏、久不干。
- 【判据】三看：
  1. **看挂**：竹片挑起，墨成连续细线不断，落下能堆起又慢慢摊平；
  2. **看转**：手指蘸墨搓开再分开，拉出的丝短而有力；
  3. **看干**：印在废纸上，半日不粘手、不蹭脏，才算合格。

【经验】印刷故障多半是墨的问题而不是版的问题：
| 现象 | 原因 | 处理 |
|---|---|---|
| 字口糊、笔画并 | 墨太稀或上墨太多 | 加稠、少蘸、勤擦版 |
| 印迹发花、缺笔 | 墨太稠或墨里夹粗粒 | 再研、加少量清油、回锅熬 |
| 印完不干、叠纸粘连 | 连结料没熬到（或用了不干性油） | 换干性油，重熬；晾架分开 |
| 墨色发灰 | 用了低等烟或烟受潮 | 换料、干燥后重研 |
| 版上积墨成垢 | 墨太稠、刷不匀 | 稀释、换软刷 |

## 七、装订：从散页到能翻十年的书

【史实】中国古籍装订的演进大致是：卷轴 → 经折装 → 蝴蝶装 → 包背装 → 线装。
线装是最后成熟、也最适合手工规模化的一种。

【经验】推荐路线：**先做线装，不要先挑战精装。**
线装的好处是——材料只要纸、线、糨糊、硬纸（书皮）；
工具只要锥子、针、裁刀、夹板；坏了能拆开重装；
且**线与纸同寿，不存在"胶老化整本散架"的问题**。

**线装六步（可照做）：**
1. **折页**：印好的纸按版心中缝对折，字面朝外（具体向以实际版式为准，
   先拿废纸试一张确认）；
2. **配页**：按页码叠齐，**必须"配后查"**——按顺序逐帖点数，错一页全书作废；
3. **齐栏（撞齐）**：书口与书脚在桌面上墩齐，这是装订质量的**第一判据**；
4. **打眼**：四眼法最常用；眼位距书脊约一指，四眼等分；
   【判据】眼要垂直、上下贯通，歪了线就拉不平；
5. **订线**：双股麻线或丝线，从第二眼起针，来回穿锁，最后回到起点打结埋入眼内；
   【判据】线要拉紧但**不能勒进纸里**——勒进纸里的线迟早把纸割断；
6. **装书皮与护叶**：前后加两三张空白护叶，再上硬皮；书皮与书芯只粘书脊一条，
   **不可满粘**（满粘会拉着书页一起裂）。

【科学】糨糊：淀粉糨糊（面粉洗出面筋后的淀粉浆最好）适合纸；
动物胶（见甲部煮胶）黏性强但**干后收缩大、易脆、易招虫**，
用于纸要稀释并加少量明矾（防腐）【存疑】加矾会加速纸张酸化，
**重要书籍慎用**，一般册子可用。
【判据】糨糊要"稀而不漏、黏而不厚"，薄薄一层足够；宁稀勿厚。

【经验】装订的"三防"：**防潮、防虫、防压**。
- 防潮：书柜离墙离地，雨季通风，书中夹吸潮纸；
- 防虫：芸香草、樟木片、定期翻晒（**晒书要在阴凉通风处，不可暴晒**）；
- 防压：书平放不竖挤、不堆叠过高。
【判据】一年后抽查：书页不发黄脆、线不断、页不脱，就算立住了。

## 八、判据与故障排查

| 现象 | 原因 | 处理 |
|---|---|---|
| 墨锭开裂 | 胶少、干燥过快、捶打不足 | 回炉重和（加水化开墨团，补胶重捶），阴干 |
| 墨锭发霉发臭 | 胶料腐败、加蛋白未干透、环境潮 | 弃用发霉部分；改少加或不加蛋白，充分阴干 |
| 墨色发灰不黑 | 烟的等级低或掺了杂质 | 换清烟；水选分级（细烟沉得慢，取上层） |
| 墨掉渣 | 胶太少或捶打不够 | 补胶重捶 |
| 墨滞笔、下墨不畅 | 胶太多 | 掺烟重捶；或改作印刷墨 |
| 写字洇纸 | 纸未施胶（见册 12 造纸）或墨太稀 | 先解决纸；墨加稠 |
| 书页散、线断 | 线细、眼太靠边、勒纸 | 换粗线、眼位内移、改订法 |
| 书页发黄发脆 | 酸（明矾、劣质糨糊）或潮 | 控制用矾，改淀粉糨糊，改善存放 |
| 卷边不平 | 潮、压、装时未墩齐 | 重新压平（重物夹压数日），改存放方式 |

【判据】"好墨"的三条土检验（不需要仪器）：
1. **看**：断面乌黑发亮、无砂眼、无白点；
2. **磨**：磨时无声不粘、磨出的墨汁细腻无渣；
3. **写**：写在纸上干后**不洇、不灰、不脱**，遇水微晕而不散（可作防伪判据）。

## 九、安全红线

1. **烧烟取烟的窑是火灾与中毒双重风险。** 取烟棚是纸糊席围的密闭长棚，
   一点即着：窑址要远离住房与柴草，灭火用水与沙土常备，**人离火灭**。
2. **一氧化碳**：不完全燃烧产生的一氧化碳无色无味，
   在烟棚、封闭书房内烧炭取暖/烧烟会致命。【判据】头晕、恶心、乏力即撤，
   **通风第一**，不要"忍一忍就好了"。
3. **松香与油烟的粉尘**：长期吸入伤肺，作业时在上风口、戴湿布口罩、
   不要把脸凑近取烟口。
4. **铅、汞、砷类的颜料与添加剂一律不用。**
   传统颜料中确实存在含铅（铅白、黄丹）、含汞（朱砂）、含砷（雄黄、雌黄）者；
   【红线】本册**不推荐**在墨与装订中使用任何有毒矿物添加物，
   尤其不得用于儿童可能接触的物件与食器墨书。研磨有毒矿物需专器专用、
   严禁入口、作业后彻底清洗。
5. **刀具与锥子**：装订打眼、裁纸的伤都是小而深的手刺伤，
   按 医学/01 处理——**冲洗、消毒、防破伤风优先**，本册不给药物与剂量。
6. 墨与纸张是"官府最在意的两样东西"之一：
   印书、刻书在多数朝代都有管制与禁书之例（见 法律 01~04、经济 07）。
   **开印坊之前，先问清什么能印。**
