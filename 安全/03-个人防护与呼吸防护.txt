### 1. 结论先行：先消除危害，最后才穿装备

【判据】先把四句话摆出来，它们是本册的全部：

1. **PPE 是最后一道防线，不是第一道。**
   【判据】**戴上口罩不等于解决了粉尘**——
   【经验】**危害还在那里，只是隔了一层会老化、会破、会戴错的东西**；
2. **呼吸防护里最要命的是"选对"和"贴脸"。**
   【判据】**选错了（用防尘口罩防气体）等于没戴**；
   **漏了脸（没贴紧）等于没戴**——**这两条是呼吸防护全部失败的九成原因**；
3. **缺氧与未知气体，一律不进。**
   【红线】**这是有限空间作业的第一条，也是唯一没有例外的一条**；
   【判据】**过滤式呼吸器不产生氧气**，它在缺氧环境里毫无用处；
4. **装备会失效，人不会自动知道。**
   【判据】**滤材饱和、手套溶胀、绳子老化、帽壳受过撞击**——
   **这些都不会提前通知你**，所以**检查与更换必须有制度**（见第 11 节）。

【判据】因此本册的顺序是：
**先消除与替代 → 再工程控制 → 再管理与纪律 → 最后才是 PPE。**

### 3. 原理一：控制层级——五层，PPE 在最底下

【判据】控制危害的通用层级，从上到下**有效性递减**：

1. **消除（Elimination）**：【经验】**干脆不做、不用、不进**——
   【判据】**这是唯一能把风险降到零的一档**；
2. **替代（Substitution）**：【经验】**用无毒的换有毒的、用水性的换溶剂型的**；
3. **工程控制（Engineering）**：【判据】**通风、密闭、隔离、湿法、局部排风、
   防护罩**——【经验】**这一档的特点是"不依赖人的自觉"**，因此**比 PPE 可靠得多**；
4. **管理控制（Administrative）**：【判据】**轮班缩短暴露时间、培训、规程、
   警示、作业许可**；
5. **PPE（个人防护装备）**：【判据】**最后一层**——
   【经验】**它保护的是人，而不是危害本身，且完全依赖"每次都戴对"。**

【判据】**为什么 PPE 排在最后**：
【经验】**它把风险留在工作场所里，只是给每个人加了一层膜**；
**膜会破、会漏、会忘、会嫌麻烦不戴**——
【判据】**所以在决定"发口罩"之前，一定要先问三遍"能不能不让粉尘产生"。**

### 4. 原理二：危害五类与"看不见的才是杀手"

【判据】按危害性质分五类，各自的"可见性"差别极大：

| 类别 | 例子 | 可见吗 | 关键判据 |
|---|---|---|---|
| **物理** | 撞击、坠落、卷入、割刺、高低温、噪声、振动、触电 | **可见**（能看到机器与高度） | **能加装防护罩、能隔离、能挂牌** |
| **化学** | 粉尘、烟、气体、蒸汽、飞溅 | **多半看不见** | **靠气味判断是错的**：嗅觉会疲劳、有的气体无味、有的嗅阈高于危险浓度 |
| **生物** | 病原、锐器、动物、粪污 | **看不见** | **一律按"有"处理**（见 `医学/05`） |
| **辐射** | 电离辐射、紫外、强光、激光 | **完全看不见** | **时间、距离、屏蔽三件事**（见 `电力/07`） |
| **人机工效** | 姿势、负重、重复、照明、疲劳 | **看不见** | **疲劳是事故的前奏** |

【判据】三条由此而来的硬结论：

1. **"闻不到就没事"是最危险的一条经验**——【红线】
   **硫化氢会麻痹嗅觉，一氧化碳完全无味，缺氧没有任何感觉**；
2. **"看得见的危险"反而死人少**：【经验】**人天生怕看得见的东西**；
3. **危害识别要写下来**：【判据】**每个作业点先列一张"这里有什么危害"的清单**，
   然后再谈用什么装备（见 `安全/01` 的风险图）。

### 5. 原理三：PPE 谱系与"没有万能手套"

【判据】按部位，各部位的核心判据如下（只给选型原则，不给型号与等级）：

| 部位 | 装备 | 核心判据 |
|---|---|---|
| **头** | 安全帽 | **帽壳受过一次撞击就要换**；下颌带要系上 |
| **眼面** | 护目镜、面屏 | **侧方也要挡**；**镜片起雾＝看不清＝等于没戴** |
| **听力** | 耳塞、耳罩 | **戴不进去等于没戴**；【判据】**噪声造成的听力损失不可逆** |
| **手** | 手套 | **没有万能手套**：防割的不防化、防化的不耐热、耐热的笨重 |
| **足** | 安全鞋 | **防砸＋防刺穿＋防滑**按工况选；**绝缘鞋不是万能的电绝缘** |
| **身体** | 防护服 | **材料决定用途**：防化、阻燃、防热、防割各不相同 |
| **坠落** | 安全带、绳、挂点 | **挂点比带子重要**（见第 9 节） |
| **呼吸** | 口罩、面具、供气 | **选对 + 贴脸**（见第 6、7 节） |

【判据】**手套这一条最值得单独说**：【经验】
**选错手套是最常见的伤害原因之一**——
【科学】**化学防护手套的关键不是"厚"，是"材料对不对"**：
**有些溶剂能在几分钟内穿透看起来很厚的手套，而且不留下任何痕迹**；
【判据】**凡是让手套变软、发胀、发黏、变色的溶剂，都说明它正在穿透**——
**出现任何一种，立即换掉并换一种材质。**

【判据】**防护服的热应激**：【经验】
**越严密的防护服越热**——【判据】**闷热会让人提前摘掉它**，
**所以在高温环境里，防护与轮换时间必须一起设计**（见第 8 节）。

### 6. 原理四：呼吸防护——过滤式与供气式的分界线

【判据】呼吸防护只有两大类，分界线是**"空气本身够不够"**：

#### ① 过滤式（靠滤材净化周围的空气）

- 只**过滤颗粒物**（粉尘、烟、雾）或**吸附气体/蒸汽**（靠活性炭等吸附材料）；
- 【科学】**它不产生氧气，也不改变氧含量**；
- 【红线】**因此在缺氧环境里毫无用处**；
- 【判据】**颗粒物过滤与气体过滤是两回事**：
  **一个普通的防尘口罩不能防气体**，这是最常见的误用；
- 【红线】**滤材会饱和**：【判据】
  **吸附材料饱和后不再起作用，而且"饱和"没有明显征兆**——
  【经验】**"闻到味道了"往往已经晚了**，所以**必须按时间或条件强制更换**。

#### ② 供气式（从别处带来干净空气）

- 【判据】**缺氧、未知气体、高浓度污染**这三类情况下**只能用供气式**；
- 【经验】**它需要气源、管路或气瓶、压力调节与监护**——
  【红线】**本册明确劝退自制供气系统**：
  **用错气源（如压缩空气未经过滤与除油除水、或误接其他气体）可直接致命**；
- 【判据】**供气式作业必须有第二个人在外监护并保持联络**。

【判据】**两条由此而来的硬结论**：

1. **不知道浓度是多少时，一律按"很高"处理**；
2. **不知道氧气够不够时，一律按"缺氧"处理**——**这一条救过最多人的命。**

### 7. 原理五：密合度是呼吸防护的第一要素

【判据】这是本册最实用的一节。
【经验】**一个戴得很贴合的普通口罩，胜过戴得漏气的"高级"口罩**——
【科学】因为**空气永远走阻力最小的路**：**脸与口罩之间的缝，阻力远小于滤材**，
所以**漏气时吸进来的几乎全是未过滤的空气**。

【判据】影响密合的六件事：

1. **胡须与胡茬**：【判据】**有胡须的地方密合不了**，这是硬性事实；
2. **脸型与尺寸**：【经验】**同一款口罩对不同脸型效果差很多**——
   **必须试戴，不能只看说明**；
3. **戴眼镜起雾**：【经验】**雾从上边缘出来，通常说明上方在漏**；
4. **说话、转头、低头**：【判据】**动作会破坏密合**——
   所以**密合检查要在动起来之后再做一次**；
5. **系带的松紧与位置**：【经验】**太松漏气，太紧疼且变形也会漏**；
6. **重复使用后的变形**：【判据】**鼻夹与边缘一旦变形就密合不了**。

【判据】**密合自检的两个动作**（每次戴上都做，很简单）：

- **正压检查**：**轻轻呼气，感觉口罩微微鼓起、且边缘没有漏气**；
- **负压检查**：**轻轻吸气，口罩应微微塌陷、且边缘不进空气**；
  【经验】**如果能在鼻梁、脸颊或下巴处感觉到气流，就要重新戴。**

【判据】**本册不给任何"防护因数"数字**：
【经验】**那些数字是在实验室里、在密合完美且经过适合性检验的条件下测出来的**，
**实际防护效果取决于你的脸**——**给数字会让人高估自己在受保护。**

### 8. 原理六：防护服、隔热与热应激

【判据】防护服按功能分四类，选错一样没用：
**防化、阻燃/防热、防割/耐磨、防液体喷溅/防生物**。

【经验】四条实用判据：

1. **材料决定用途**：【判据】**天然纤维遇火会燃烧、熔融纤维遇火会熔融粘在皮肤上**——
   两者都不能当阻燃服用；
2. **覆盖要连续**：【经验】**防护服与手套、鞋、面具之间的接缝是弱点**——
   【判据】**"整套"比"每件都好"重要**；
3. **污染后脱下比穿上更危险**：【红线】**脱防护服时最容易污染自己**——
   【经验】**脱的顺序与动作要事先演练，脱完立即洗手**；
4. **热应激**：【判据】**严密防护＋重体力＋高温 = 中暑**——
   【经验】**必须轮换、补水、设阴凉休息点，并有人观察**（见 `分册/基础篇/02`）。

### 9. 原理七：坠落防护——挂点比带子重要

【判据】坠落防护系统的四个环节，**最弱的一环常常不是带子**：

1. **挂点（锚点）**：【判据】**这是最常被忽略也最致命的一环**——
   【经验】**挂在一个不结实的檐檩上，等于没挂**；
   【判据】**挂点要能承受坠落产生的冲击力，而不是只承受体重**
   （冲击力远大于体重）；
2. **连接件**（绳、缓冲包、挂钩）：【判据】
   **缓冲包的作用是延长减速时间以降低冲击力**；
3. **安全带（全身式）**：【判据】
   **全身式优于腰带式**——**腰带会把冲击力集中在腰部并造成内脏损伤**；
4. **净空距离**：【经验】**下面要有足够空间让你减速停下**——
   【判据】**在很矮的高度作业时，坠落防护可能来不及生效**，
   这时要靠**脚手架、护栏、平台**这类"集体防护"。

【判据】**优先顺序**：**能不上去就不上去 → 能用平台护栏就用 → 最后才用安全带。**
【红线】**高处作业不得单人进行**，**地面要有人**；
**梯子是最容易出事的一件工具**：【经验】**梯子要有人扶、要放稳、要角度合适、
不得站在最上面几级**（见 `工艺/12`）。

### 10. 原理八：机械安全的三件东西（防护罩、联锁、急停）

【判据】机械伤害几乎全部发生在**"运转中的运动件"**：
卷入、挤压、切割、飞出、撞击。防护的三件东西，可靠性依次降低：

1. **固定防护罩**（最可靠）：【判据】
   **把危险区物理隔开**——【经验】**它不依赖任何人做对任何事**；
   【红线】**拆掉防护罩"为了方便"是最常见的机械伤害起因**；
2. **联锁**：【科学】**打开防护门即切断动力并停止运动**；
   【判据】**联锁必须真的切断能量，而不只是"报警"**——
   【红线】**联锁被短接／被绑住＝没有联锁**；
3. **急停**：【判据】**最后的手段**——
   **急停按钮必须硬接线、必须能随手拍到、必须断电而不是只停程序**
   （见 `电子/02`）；【经验】**急停按下后必须人工复位**，
   **不得自动重启**（自动重启会把人伤两次）。

【判据】**能量隔离四步**（与 `工艺/13` 完全一致，是本册最该背的四句）：
**断电断源 → 隔离锁定（挂牌）→ 释放残余能量 → 验电／验证**
——【红线】**四步缺一不可，且"验证"这一步永远不能省**。

### 11. 原理九：选型四问与更换判据

【判据】每次选防护装备，按这四问走一遍：

1. **危害是什么？**（粉尘／气体／飞溅／高温／坠落／触电／辐射？）
2. **强度多大？**（浓度、温度、高度、能量——**不知道就按"很高"处理**）
3. **多久？**（暴露时间决定更换频率与是否要轮换）
4. **有没有次生风险？**（缺氧？可燃？高温？会不会窒息或中暑？）

【判据】**更换判据（这是最实操的一节）**：

- **呼吸滤材**：**闻到/尝到味道、呼吸阻力明显增大、脏了、湿了、变形了、
  到期了**——**任一条出现即更换**；【经验】**"还能用"的口罩往往已经失效**；
- **手套**：**发胀、变软、变色、发黏、破损、渗透**——任一条即换；
- **安全帽**：**受过一次撞击即换**；**老化发脆即换**；
- **绳带与安全带**：**受过一次坠落冲击即报废**（即使看起来完好）；
  **磨损、割伤、化学污染、日晒老化**都要换；
- **防护服**：**污染后按污染处理**，**一次性用的绝不重复使用**。

【判据】**存放与检查**：【经验】
**清洁、干燥、避光、远离化学品与尖锐物**；
**每次使用前看一眼**（这是最便宜也最有效的检查）；
**建一本装备台账**（谁领的、什么时候换的，见 `工艺/13`）。

================================================================

### 12. 路线图：五级台阶（台阶一、二立刻可做）

#### 台阶一 · 认出危害并躲开（当天，零成本）

【判据】1. **每个作业点先列一张危害清单**（见第 4 节）；
2. **先问三遍"能不能不产生这个危害"**（湿法、通风、隔离、改工艺）；
3. **"不进入"是最强的防护**：【红线】**缺氧、未知气体、浓烟、
   有限空间、不稳定结构——一律不进**；
4. **两人同行，互相看得见**。

#### 台阶二 · 基础 PPE 与作业纪律（一周内）

【判据】**手套、护目镜、耳塞、硬底鞋、帽子——五件最便宜的装备先配齐**：
1. 手套按工况分几种放，**并让每个人知道哪种干什么**；
2. 护目镜要**侧方也挡、不起雾**；
3. **作业纪律**：不戴护具不做、不拆防护罩、不单人高处作业、
   不停机不伸手（见 `工艺/13`、`机械/01`）。

#### 台阶三 · 呼吸防护的选型与密合（需培训）

【判据】1. **先判断是颗粒物还是气体**（这是选型的分水岭）；
2. **试戴 + 密合自检（正压/负压）**，**每人每次都要做**；
3. **定更换条件并写进规程**（闻到/阻力大/到期，见第 11 节）；
4. **培训比装备重要**：【经验】
   **会戴的人用普通口罩，胜过不会戴的人用好口罩。**

#### 台阶四 · 坠落防护、有限空间与供气（需专业装备与监护）

【判据】**本册在这一级明确劝退"土法上马"**：
1. **坠落防护**：**挂点要可靠、全身式安全带、有人监护、下方清场**；
2. **有限空间**：**先通风、先检测、有监护、有绳索与救援方案，缺一不进**
   （见 `环境/01`、`环境/02`、`工艺/17`）；
3. **供气式**：**必须由专业设备与训练支撑，绝不自制气源。**

#### 台阶五 · 完整的职业健康与防护用品体系（明确劝退）

【判据】需要**检测能力（测浓度、测氧、测噪）、适合的定量适合性检验、
职业健康检查与法规体系**——【经验】
**没有检测，所谓"防护"只是在赌**；
【判据】**这一级只能靠长期的专业体系建设**（见 `医学/05`、`工艺/16`）。

================================================================

### 13. 为什么做不出来：四道门槛

1. **看不见的危害无法凭感觉判断**：【判据】
   **这是 PPE 与别的防护最大的不同**——**没有检测，就不知道该防什么、防得够不够**；
2. **"不方便"会战胜"安全"**：【经验】
   **闷、热、雾、勒、慢**——**任何一件不舒服的装备都会被悄悄摘掉**；
   【判据】**所以选型时"愿意戴"和"能防护"同等重要**；
3. **耗材的可持续性**：【判据】
   **滤材、手套、药剂都是消耗品**——**没有补给，防护体系会在最需要的时候断掉**；
4. **密合与培训无法靠发装备解决**：【经验】
   **发下去一万个口罩，不如培训一百个人学会戴。**

### 14. 判据与故障排查

| 现象 | 最可能的原因 | 判据／处置 |
|---|---|---|
| 戴了口罩还是咳嗽、有粉尘味 | 漏气或选错类型 | **重戴并做正压/负压自检**；颗粒物与气体要分清楚 |
| 眼镜起雾 | 上边缘漏气 | 调整鼻夹与系带；**起雾＝在漏** |
| 闻到溶剂味 | 滤材已饱和或类型不对 | **立即撤离更换**；换材质并缩短使用时间 |
| 手套发胀发软 | 溶剂正在穿透 | **立即更换并换另一种材质** |
| 耳塞戴着还是吵 | 没戴进去 | **重新佩戴**；噪声伤害是累积且不可逆的 |
| 安全带挂着却不放心 | 挂点不可靠 | **换挂点**；挂点必须能承受坠落冲击 |
| 防护服内闷热难忍 | 热应激 | **轮换、补水、阴凉休息**，并有人观察 |
| 脱下防护服后皮肤沾到污染物 | 脱卸顺序错 | **演练脱卸顺序，脱完洗手** |
| 防护罩总被拆掉 | 影响操作、没人管 | **改设计让它不影响操作**；拆罩要按违章处理 |
| 急停按下后机器又动了 | 急停只停了程序未断电 | **急停必须硬接线并人工复位**（见 `电子/02`） |
| 池子里有人晕倒，第二个人进去也倒了 | 有限空间连环事故 | **绝不盲目施救**：先通风、用绳、报警、等待专业救援 |

================================================================

### 15. 安全红线

1. **缺氧与未知气体一律不进，绝不盲目施救**：【红线】
   **有限空间事故的死者里，施救者占很大比例**（见 `环境/01`、`环境/02`、`工艺/17`）；
2. **过滤式呼吸器绝不用于缺氧与未知气体环境**；
3. **绝不自制供气系统与气源**（见第 6 节）；
4. **硫化氢、一氧化碳、缺氧三者都不能靠鼻子判断**：【红线】
   **嗅觉疲劳与无味＝致命**；
5. **绝不拆、短接、绑住防护罩与联锁**；**急停必须硬接线**（见第 10 节）；
6. **能量隔离四步缺一不做**；**"验证"那一步永远不能省**（见 `工艺/13`、`电力/03`）；
7. **高处作业绝不单人**、**梯子要有人扶**、**下方清场**；
8. **受过冲击的安全带与绳索、受过撞击的安全帽一律报废**；
9. **石棉与老旧保温材料不得扬尘作业**（见 `化工/05`、`工艺/13`）；
10. **含铅旧漆、重金属粉尘、有机溶剂、酸与氰化物盐浴**——
    【红线】**本册的立场是"不碰"优先于"防护"**（见 `冶金/02`、`冶金/03`）；
11. **不得用饮用水、食物容器盛装化学品，不得用嘴吹吸任何管路**；
12. **噪声与辐射的伤害是不可逆的**：【判据】
    **听力损失与辐射损伤没有"补回来"的办法**（见 `电力/07`）；
13. **现实中劳动防护、职业病防治、特种设备与高处、有限空间作业受法律管制**
    （见 `法律/06~10`），**作业许可与防护标准一律以当地现行规定为准**，
    本册不构成任何现实中的防护与作业依据。
