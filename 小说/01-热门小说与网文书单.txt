热门小说与网络小说清单（穿越随身·纯文本版）
================================================
【重要说明·先看】
本册不收录任何仍在版权期内的作品正文——把现代网文原文背去古代"发表"，
既无必要（你带不过去全文），也有风险。这里提供的是三样真正有用的东西：
  1）热门作品清单 + 类型定位 + 核心设定（便于你判断"哪个套路最受欢迎"）
  2）可迁移的"故事骨架"（桥段、人设、金手指类型）
  3）公版作品清单（古典小说，可放心讲、改编、出书，无版权问题）
真正能在古代安身立命的是"讲故事的能力"和"公版名著"，不是背诵现代网文。

------------------------------------------------
一、当代热门作品速览（按类型，供你判断流行口味）

【玄幻·升级流】
- 《斗破苍穹》（天蚕土豆）：废柴逆袭 + 退婚开局 + "三十年河东三十年河西"，
  核心爽点是"等级压制 + 打脸循环"。最易被古代听众接受的骨架。
- 《斗罗大陆》（唐家三少）：武魂体系 + 学院 + 团队战，设定清晰、适合改编说书。
- 《完美世界》《遮天》（辰东）：宏大世界观 + 长生主题，适合长篇连载。
- 《诡秘之主》（爱潜水的乌贼）：蒸汽朋克 + 克苏鲁 + 严密的力量体系，
  设定控最爱；古代听众未必适应，但"序列晋升"骨架极好用。

【仙侠·修真】
- 《凡人修仙传》（忘语）：凡人流鼻祖，主角资质平庸、靠谨慎与资源爬升，
  "苟"的美学。古代修仙题材可借鉴其"资源—境界—寿元"的量化体系。
- 《诛仙》（萧鼎）：情义悲剧向，文笔取胜。
- 《仙逆》《一念永恒》（耳根）：执念驱动 + 反转。

【历史·穿越·架空】
- 《赘婿》（愤怒的香蕉）：穿越者以现代商业/组织手段介入古代，慢热写实。
  与你的处境最相关，其中的"技术落地—资本—权力博弈"逻辑很有参考价值。
- 《新宋》（阿越）：技术改良与社会制度冲突，考据扎实。
- 《回到明朝当王爷》《极品家丁》类：轻松向，官场与后宅两条线。
- 《庆余年》（猫腻）：权谋 + 现代意识冲突。

【悬疑·探险】
- 《盗墓笔记》（南派三叔）、《鬼吹灯》（天下霸唱）：
  "组队—机关—怪异—逃生"单元剧结构，最适合说书人分段讲。

【科幻】
- 《三体》（刘慈欣）：黑暗森林、降维打击，概念震撼；古代听众难懂，
  但"猜疑链""技术爆炸"可作为思想实验讲给士人听。
- 《球状闪电》《流浪地球》：概念型，适合短篇改编。

【都市·言情】
- 都市爽文：神医/兵王/重生类，套路密集，适合"短平快"取悦听众。
- 言情经典：《何以笙箫默》等，核心是"错过—重逢—执念"。

二、真正能带走的：故事骨架清单（可自由组合）

【骨架 A：废柴逆袭】
开局受辱（退婚/被逐）→ 获得奇遇（老爷爷/秘境/传承）→ 隐藏实力 →
家族大比一鸣惊人 → 外出历练 → 打脸旧敌 → 更大舞台。
要点：每一次打脸都要有"观众"，且观众身份要升级。

【骨架 B：技术流改造古代】
穿越者用现代知识解决眼前危机（治病/增产/造器）→ 引起注意 →
被招揽或被打压 → 建立自己的产业（作坊/商队/学院）→
卷入权力斗争 → 以技术与组织力量破局。
要点：技术必须"降维但可复现"，别一上来造蒸汽机（见技术分册的资源约束）。

【骨架 C：探案单元剧】
奇案开场 → 现场勘验（用你的现代常识：指纹/毒物/时间线）→
嫌疑人若干 → 误导 → 关键证据反转 → 真凶另有其人 → 留下长线伏笔。
要点：古代没有法医，你的"常识"就是金手指，且成本低、风险小。

【骨架 D：寻宝探险】
地图/传说 → 组队（各有专长）→ 上路 → 途中怪象（自然现象可科学解释）→
机关（物理陷阱）→ 得宝 → 代价（同伴伤亡/诅咒实为病毒或毒素）。

【骨架 E：种田基建】
落脚 → 解决温饱（见技术分册：制碱/制皂/育种/肥料）→ 卫生（青霉素）
→ 建立信用（治病救人）→ 形成聚落 → 面对官税与豪强 → 组织自卫。
要点：这是穿越者最稳的活法，也是本手册技术部分的实际用途所在。

【金手指类型库】
1. 知识型（最稳）：现代科学常识、医学、农业、数学。
2. 器物型：随身物品（打火机、镜子、钢制品、抗生素、种子）。
3. 体质型：免疫、力量、寿命——最不可控，慎用。
4. 系统型：只适合说出来哄人，实际不存在，别当真。

四、在古代"说书/写书"的实操建议

1. 先讲单元剧：每回一个完整小故事（探案、怪谈、侠义），比连载长篇更能留住听众。
2. 章回体格式要熟：开头"话说……"，结尾"欲知后事如何，且听下回分解"，
   每回字数约 3000–5000 字，每回末尾留悬念。
3. 传播路径：说书（茶楼）→ 抄本（书生传抄）→ 刻印（书坊）→ 评点本（名人作序）。
   想赚钱，先拿下书坊合作；想出名，先让士人传抄。
4. 内容安全：避开影射当朝、避讳皇帝名讳、避开淫秽描写（会被禁毁）、
   涉及宗教要谨慎（尤其回教、喇嘛教等敏感题材）。
5. 别用后世才有的词（"革命""公司""科学"），用词要合时代；也别署真实作者名
   （署笔号最稳，如"XX山人""XX居士"）。
6. 一部书的生命周期：先求"被传抄"，再求"被刊刻"，最后才有"署名"。
   一开始就把名字刻上去，反而容易被人夺稿。
