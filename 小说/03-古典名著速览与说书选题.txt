古典名著速览与说书选题（公版·可放心使用）
================================================
说明：本册收录已进入公有领域的古典作品，含故事梗概、可直接讲述的经典桥段清单、
以及少量原文开篇（公版，可自由引用）。这是你穿越后最安全的"内容库"——
既能赚钱，又不会有版权或时代错位的麻烦。

------------------------------------------------
一、《三国演义》（罗贯中）

故事梗概：东汉末年黄巾起义，天下大乱。刘备、关羽、张飞桃园结义，
与曹操、孙权三分天下。经官渡、赤壁、夷陵三大战役，最终司马氏篡魏，
三国归晋。核心是"义"与"势"的冲突，尊刘抑曹。

开篇词（《临江仙》，杨慎）——几乎人人会背，说书定场极佳：
滚滚长江东逝水，浪花淘尽英雄。是非成败转头空。青山依旧在，几度夕阳红。
白发渔樵江渚上，惯看秋月春风。一壶浊酒喜相逢。古今多少事，都付笑谈中。

开篇第一句：话说天下大势，分久必合，合久必分。

可讲的经典桥段（每次一回，最适合茶楼）：
桃园结义 / 温酒斩华雄 / 三英战吕布 / 连环计（貂蝉）/ 煮酒论英雄 /
千里走单骑 / 官渡之战 / 三顾茅庐 / 长坂坡（赵云救阿斗）/ 舌战群儒 /
草船借箭 / 借东风 / 火烧赤壁 / 华容道 / 三气周瑜 / 单刀赴会 /
水淹七军 / 刮骨疗毒 / 败走麦城 / 空城计 / 挥泪斩马谡 / 死诸葛吓走生仲达

人物标签速记：
刘备（仁）、关羽（义）、张飞（猛）、诸葛亮（智）、赵云（忠勇）、
曹操（奸雄）、周瑜（才高气狭）、司马懿（忍）、吕布（反复）。

二、《水浒传》（施耐庵）

故事梗概：北宋末年，一百零八位好汉先后被逼上梁山，聚义后受招安，
征方腊后星散凋零。核心是"逼上梁山"与"忠义难两全"。

可讲的经典桥段：
鲁智深拳打镇关西 / 倒拔垂杨柳 / 林冲风雪山神庙 / 杨志卖刀 /
智取生辰纲 / 宋江怒杀阎婆惜 / 武松景阳冈打虎 / 斗杀西门庆 /
醉打蒋门神 / 血溅鸳鸯楼 / 三打祝家庄 / 大破连环马 / 三山聚义 /
晁盖曾头市中箭 / 卢俊义上山 / 招安 / 征方腊

三十六天罡绰号速记（常用）：
宋江·及时雨 / 卢俊义·玉麒麟 / 吴用·智多星 / 林冲·豹子头 /
鲁智深·花和尚 / 武松·行者 / 李逵·黑旋风 / 燕青·浪子 /
花荣·小李广 / 张顺·浪里白条 / 时迁·鼓上蚤 / 公孙胜·入云龙

三、《西游记》（吴承恩）

故事梗概：花果山石猴成王，学艺于菩提祖师，大闹天宫被压五行山五百年；
后保唐僧西天取经，历八十一难，终成正果。表面神魔，实则修心。

开篇（可直接背）：
混沌未分天地乱，茫茫渺渺无人见。自从盘古破鸿蒙，开辟从兹清浊辨。
覆载群生仰至仁，发明万物皆成善。欲知造化会元功，须看西游释厄传。

可讲的经典桥段：
石猴出世 / 拜师学艺 / 龙宫得金箍棒 / 大闹地府 / 弼马温 / 大闹天宫 /
五行山 / 收白龙马 / 收八戒（高老庄）/ 收沙僧（流沙河）/
三打白骨精 / 真假美猴王 / 火焰山（三调芭蕉扇）/ 女儿国 /
车迟国斗法 / 金兜山 / 狮驼岭 / 通天河 / 取真经 / 成正果

八十一难可拆成 81 个独立小故事，是茶楼连讲三个月的素材库。

四、《红楼梦》（曹雪芹）

故事梗概：贾府由盛转衰，宝黛钗爱情悲剧为主线，写尽人情世态。
适合改编成"才子佳人"戏文，但说书难度高（需听众有文化）。

金陵十二钗判词（节选其一）：
可叹停机德，堪怜咏絮才。玉带林中挂，金簪雪里埋。（黛玉、宝钗）

可讲的经典桥段：
黛玉进府 / 宝黛初会 / 刘姥姥进大观园 / 元春省亲 / 宝玉挨打 /
黛玉葬花 / 海棠结社 / 抄检大观园 / 黛玉焚稿 / 宝玉出家

名句：满纸荒唐言，一把辛酸泪。都云作者痴，谁解其中味？

五、其他中国古典（说书富矿）

《封神演义》：武王伐纣 + 神魔斗法，哪吒闹海、姜子牙、妲己、诛仙阵。
《隋唐演义》：秦琼卖马、程咬金、瓦岗寨、罗成、单雄信，武戏素材最多。
《说岳全传》：岳飞精忠报国，注意：涉及民族题材，讲前先看清当朝忌讳。
《杨家将演义》：忠烈一门，佘太君、穆桂英，适合女听众。
《七侠五义》《小五义》：包公 + 展昭 + 白玉堂，公案侠义，最适合改编探案。
《聊斋志异》（蒲松龄）：短篇志怪，每篇 1000–3000 字，最适合一回讲完；
  名篇：聂小倩、画皮、崂山道士、促织、席方平、婴宁、连城、阿宝。
《三言二拍》：市井白话短篇，反映商人、婚恋、公案，素材最接地气；
  名篇：杜十娘怒沉百宝箱、卖油郎独占花魁、乔太守乱点鸳鸯谱、金玉奴棒打薄情郎。
《镜花缘》：海外奇国，讽刺寓言，含大量"奇异技术"描写，可启发你的技术落地。
《儒林外史》：讽刺科举，范进中举、严监生临死伸两指，适合讲给读书人听（会得罪人，慎用）。
《东周列国志》：春秋战国，故事最多，史实性强。

民间传说（必会）：
白蛇传（游湖借伞—端午现形—盗仙草—水漫金山—雷峰塔）
梁山伯与祝英台（同窗—十八相送—化蝶）
牛郎织女 / 天仙配（董永七仙女）/ 孟姜女 / 嫦娥奔月 / 精卫填海 /
愚公移山 / 后羿射日 / 大禹治水

六、世界公版名著（可"转述"给古人听，极有新奇感）

《鲁滨逊漂流记》（笛福）：荒岛求生，与本手册技术部分高度互补。
《基督山伯爵》（大仲马）：越狱 + 复仇 + 巨额财富，爽文鼻祖。
《三个火枪手》：侠义与宫廷。
《格列佛游记》：小人国、大人国，讽刺，可当志怪讲。
《海底两万里》《八十天环游地球》（凡尔纳）：科幻冒险，讲给古代听众极具冲击力。
《福尔摩斯探案》（柯南·道尔）：探案模板，直接拿来提高你的"断案"段位。
《一千零一夜》：框架故事，故事套故事，非常适合连讲 1001 夜。
《伊索寓言》《格林童话》《安徒生童话》：短，适合讲给孩童（快速建立"慈爱"人设）。
莎士比亚戏剧：罗密欧与朱丽叶、哈姆雷特、李尔王、威尼斯商人。
《堂吉诃德》：骑士幻想，喜剧。
《荷马史诗》：特洛伊战争、奥德修斯归乡，可讲十年。
《十日谈》：框架故事，注意有荤段子，讲前先筛。

提醒：转述时用自己的话重讲，不要照搬某个现代译本的译文（译本另有版权）；
人名地名要"归化"（改成听众能记住的中式称呼或保留简短音译）。

七、说书实操：三个月连讲排期示例

第 1–10 天：聊斋短篇（每天一篇，立"奇人"人设）
第 11–30 天：三言二拍市井故事（拉近与市民距离）
第 31–60 天：水浒传（武松十回最吸客）
第 61–90 天：西游记（八十一难，可长期讲）
穿插：每讲完一段，抛出"下回"悬念，并让听众点单（点单加钱）
