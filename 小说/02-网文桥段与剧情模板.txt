网文桥段与剧情模板（穿越随身·纯文本版）
================================================
说明：以下均为"可自由组合的通用桥段"，是你自己编故事时的零件库。
不涉及任何具体作品的原文。用法：选一个骨架（见书单册）+ 若干桥段 →
拼成章回 → 每回留悬念。

------------------------------------------------
一、开局十式（第一章定生死）

1. 退婚流：当众被退 → 立誓 → 三年后打脸。
2. 救人流：路上救下重伤者 → 对方身份惊人 → 卷入大事件。
3. 献计流：众人束手 → 主角一句话点破 → 被赏识。
4. 露一手流：当众治病/破案/算账 → 名声初起。
5. 落难流：主角已是罪身/奴籍 → 从最低处爬起。
6. 记忆复苏流：昏迷醒来 → 两世记忆融合 → 性格大变引起怀疑。
7. 器物流：随身物品（镜子/火机/钢刀）被当作异宝。
8. 天象流：主角降生/穿越时出现异象 → 被当作祥瑞或妖异。
9. 误会流：被误认为某位失踪要人 → 将错就错 → 后续揭穿危机。
10. 赌约流：与人立赌 → 用现代知识稳赢 → 赚第一桶金。

------------------------------------------------
二、打脸循环（爽点发生器，五步）

第一步：目标轻视主角（身份、出身、实力、钱财任一维度）
第二步：公开场合（必须有观众），观众身份越高越好
第三步：主角给出"不可能"的承诺（治好绝症、三日交货、当场破案）
第四步：过程受阻（缺药、缺人、被人使绊），制造紧张
第五步：反转达成 → 对方付出代价 → 旁观者重新定价主角的价值

要点：打脸对象要"有身份但不致命"，否则后续无法收场；
每次打脸后都要给主角带来实际资源（钱、人、名），别只赚吆喝。

------------------------------------------------
三、危机与反转清单（随手取用）

- 药是假的 / 药被掉包 → 主角当场验毒（用现代化学常识：明矾、银针、酸碱显色）
- 被人诬告 → 主角用时间线（谁在何时在何地）反证
- 账目出错 → 主角用复式记账/珠算速核对当场查出漏洞
- 粮仓失火 → 主角指出是自燃（湿热发酵）而非人为，破解栽赃
- 疫病爆发 → 隔离 + 煮沸饮水 + 石灰消毒（见技术分册）
- 山洪将至 → 主角据上游雨量与水位预判，劝迁移
- 被人下毒 → 主角用催吐 + 活性炭（炭粉）吸附急救
- 兵器折断 → 主角指出是锻造缺陷（含磷/夹渣），现场重锻立威
- 疑难杂症 → 实际是寄生虫/维生素缺乏/糖尿病，用饮食与卫生解决
- 伪造文书 → 主角从纸张、墨迹、印泥、避讳字找出破绽

------------------------------------------------
四、人物模板（配角只需贴标签，节省脑力）

1. 忠仆：憨直、力大、忠心，负责"被抓—被救"制造危机。
2. 老儒：顽固但正直，负责"质疑—被说服—成为声望背书"。
3. 美艳掌柜：消息灵通，负责情报与铺子渠道。
4. 落魄高手：有伤/有毒瘾/有旧仇，负责"被救后效忠"。
5. 纨绔子弟：轻浮但不坏，负责"前期打脸—后期收为小弟"。
6. 清官：想做事但无权，负责"给主角官方身份"。
7. 酷吏：聪明而狠，负责"长期压力源"。
8. 医者：传统派，负责"质疑主角医术—验证失败—拜服"。
9. 匠人：手巧保守，负责"技术实现与工艺改良"。
10. 幕后老人：前朝遗老/隐世大儒，负责"在关键时刻说出一句话改变格局"。

------------------------------------------------
五、章回体写作模板（可直接套）

第一回（立人设）
开场：一句定场诗（五绝最稳，见诗词册）→
交代地点/身份/处境 → 一件小事展示主角"不一样" →
悬念：某人/某物出现，暗示大势将起 → "且听下回分解"

中段回（推进）
承接上回悬念 → 主角行动 → 遭遇阻碍（人祸）→
用现代知识破局（给读者"学到了"的快感）→
收获（钱/人/名）→ 引出新对手（升级）→ 新悬念

高潮回（总爆发）
所有伏笔收拢 → 主角底牌尽出 → 对手败 →
付出代价（伤/友逝/暴露身份）→ 格局改变

收尾回（留余味）
善后 → 交代各人去向 → 一句诗收束 →
（长篇则埋下一卷的引子）

------------------------------------------------
六、对话与文风注意事项

1. 古代对话要"短"，多用四字短语与俗语，少用长句。
2. 别写现代心理描写（"他感到压力很大"），改写成动作与环境
   （"他握着茶盏的手紧了紧，指节发白"）。
3. 称谓要准：自称（在下/小人/某）、尊称（足下/阁下/大人）、
   谦称（犬子/拙荆/寒舍）、敬称（令尊/令爱/贵府）。
4. 度量衡要合时代：用"石、斗、升、斤、两、钱、分"；
   长度用"丈、尺、寸"；面积用"亩"；时间用"更、时辰、刻"。
5. 数字表述：古代多用"三、九、百、千、万"虚指，"三百余斤"比"327斤"合适。
6. 忌讳：避皇帝与尊长名讳；不用后世才出现的器物名称（"自鸣钟"可称，
   但"火车""电话"要按时代改）。

------------------------------------------------
七、商业变现路径（穿越者版）

第一步：茶楼说书（每日一段，先赚现钱，攒人气）
第二步：卖抄本（让书生传抄，不求钱，求传播）
第三步：与书坊签约（按"每部 X 两"或"抽成"，务必留底稿）
第四步：出评点本（请名士作序评点，身价倍增）
第五步：衍生（改编戏曲、连环画式绣像本、续作）
风险提示：
- 书坊常赖账或盗印，签约前先找人打听口碑；
- 涉及朝政、宗教、淫秽内容会被禁毁甚至获罪；
- 名气太大可能被权贵强索"代笔"，要提前想好推脱之辞（如"需静养""文思已竭"）。
